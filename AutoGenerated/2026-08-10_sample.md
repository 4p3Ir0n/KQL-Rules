## 1) Suspicious child process from TeamCity agent/server (possible CVE-2026-63077 exploitation)

**Tactic:** Execution  
**ATT&CK:** T1190 / T1059  
**Severity:** High  
**Purpose:** Detect unexpected shell or LOLBIN children spawned by JetBrains TeamCity processes, consistent with deserialization RCE via the agent polling protocol.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFileName has_any ("teamcity","TeamCity","java.exe") and InitiatingProcessCommandLine has_any ("teamcity","BuildAgent","TeamCity")
| where FileName in~ ("cmd.exe","powershell.exe","pwsh.exe","bash.exe","wscript.exe","cscript.exe","curl.exe","certutil.exe")
| project Timestamp, DeviceName, AccountName, FileName, ProcessCommandLine, InitiatingProcessFileName, InitiatingProcessCommandLine
| order by Timestamp desc
```

**Tuning notes:** Exclude sanctioned build steps that legitimately invoke shells; scope InitiatingProcess to your TeamCity install path to cut noise.

## 2) Command execution from Progress LoadMaster appliance context (possible CVE-2026-8037)

**Tactic:** InitialAccess  
**ATT&CK:** T1190  
**Severity:** High  
**Purpose:** Surface OS command execution originating from web/appliance service accounts, consistent with unauthenticated command injection in LoadMaster endpoints.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFileName in~ ("httpd","nginx","lighttpd","php-cgi")
| where FileName in~ ("sh","bash","cmd.exe","powershell.exe") and ProcessCommandLine has_any ("wget","curl","nc","chmod +x","/tmp/")
| project Timestamp, DeviceName, AccountName, FileName, ProcessCommandLine, InitiatingProcessFileName, InitiatingProcessCommandLine
| order by Timestamp desc
```

**Tuning notes:** Appliance-dependent; validate against your LoadMaster telemetry. Allowlist known health-check scripts.
