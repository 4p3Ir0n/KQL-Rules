## 1) ClickFix / ClearFake: Explorer-spawned Interpreter With Download-and-Execute Command Line

**Tactic:** Execution  
**ATT&CK:** T1204.004  
**Severity:** High  
**Purpose:** Detects the ClickFix social-engineering chain used by ClearFake and SmartApeSG, where the victim pastes an attacker-supplied command into the Windows Run dialog, causing explorer.exe to spawn PowerShell/mshta/cmd/curl with remote payload retrieval logic.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFileName =~ "explorer.exe"
| where FileName in~ ("powershell.exe","pwsh.exe","mshta.exe","cmd.exe","curl.exe","wscript.exe","cscript.exe","msiexec.exe","rundll32.exe","certutil.exe","bitsadmin.exe","conhost.exe")
| where ProcessCommandLine has_any ("http://","https://","FromBase64String","-enc","-EncodedCommand","IEX","Invoke-Expression","Invoke-WebRequest","Invoke-RestMethod","DownloadString","DownloadFile","iwr ","curl ","-w 1","WebClient","mshta","\\\\","Hidden","-nop","bitsadmin","certutil -urlcache")
| project Timestamp, DeviceName, AccountName, FileName, ProcessCommandLine, InitiatingProcessFileName, InitiatingProcessCommandLine, ProcessIntegrityLevel, ReportId
| order by Timestamp desc
```

**Tuning notes:** explorer.exe-spawned cmd.exe with UNC paths may be legitimate in some environments; allowlist known admin scripts and software-deployment UNC shares. Consider restricting FileName to powershell/mshta/curl only if cmd.exe is noisy. Pair with the RunMRU detection for higher confidence.

## 2) ClickFix Artifact: Suspicious Command Written to Explorer RunMRU Key

**Tactic:** Execution  
**ATT&CK:** T1059.001  
**Severity:** Medium  
**Purpose:** ClickFix lures instruct users to press Win+R and paste a command; Windows records it in the Explorer RunMRU registry key. This provides durable forensic evidence of the paste-and-run technique independent of the payload used.

```kusto
DeviceRegistryEvents
| where Timestamp > ago(1d)
| where ActionType in ("RegistryValueSet","RegistryKeyCreated")
| where RegistryKey has @"Explorer\RunMRU"
| where RegistryValueData has_any ("powershell","pwsh","mshta","cmd /c","cmd.exe /c","curl ","certutil","bitsadmin","rundll32","msiexec","wscript","cscript","conhost","FromBase64String","IEX","Invoke-","http://","https://","-enc","# \u2713","verification","captcha","I am not a robot")
| project Timestamp, DeviceName, AccountName, RegistryKey, RegistryValueName, RegistryValueData, InitiatingProcessFileName, ReportId
| order by Timestamp desc
```

**Tuning notes:** Admins legitimately type cmd/powershell into Run. Reduce noise by requiring RegistryValueData length > 60 characters or by requiring URL/base64/IEX indicators only. Baseline per-user: repeat offenders typing 'cmd' are benign.

## 3) EtherHiding: Blockchain RPC Endpoint Contacted by Non-Browser Process

**Tactic:** CommandAndControl  
**ATT&CK:** T1102  
**Severity:** High  
**Purpose:** ClearFake uses EtherHiding, storing payload/redirect logic in smart contracts and resolving it via public Ethereum/BSC JSON-RPC endpoints. Non-browser processes talking to blockchain RPC infrastructure is a strong C2/stage-retrieval signal.

```kusto
DeviceNetworkEvents
| where Timestamp > ago(1d)
| where RemoteUrl has_any ("bsc-dataseed","binance.org","cloudflare-eth.com","rpc.ankr.com","llamarpc.com","infura.io","alchemy.com","publicnode.com","drpc.org","blastapi.io","quiknode.pro","eth.merkle.io","nodereal.io")
| where InitiatingProcessFileName !in~ ("chrome.exe","msedge.exe","firefox.exe","brave.exe","opera.exe","iexplore.exe","msedgewebview2.exe")
| summarize Connections = count(), Endpoints = make_set(RemoteUrl, 20), FirstSeen = min(Timestamp), LastSeen = max(Timestamp)
    by DeviceName, InitiatingProcessFileName, InitiatingProcessFolderPath, InitiatingProcessCommandLine, InitiatingProcessAccountName, RemotePort
| project FirstSeen, LastSeen, DeviceName, InitiatingProcessFileName, InitiatingProcessFolderPath, InitiatingProcessCommandLine, InitiatingProcessAccountName, RemotePort, Connections, Endpoints
| order by LastSeen desc
```

**Tuning notes:** Allowlist legitimate crypto wallets, node clients and developer tooling (MetaMask desktop, Ledger Live, hardhat/node.exe on dev workstations) by InitiatingProcessFolderPath. Script interpreters (powershell.exe, mshta.exe, node.exe in user temp) hitting these endpoints should be treated as high severity.

## 4) Dead-Drop Resolver: Non-Browser Process Contacting Telegram/Steam/Social Profile Pages

**Tactic:** CommandAndControl  
**ATT&CK:** T1102.001  
**Severity:** Medium  
**Purpose:** Vidar and related stealers resolve their live C2 address from attacker-controlled Telegram channels, Steam Community profiles or social media bios before beaconing. A non-browser process fetching these pages is a reliable dead-drop resolution signal.

```kusto
DeviceNetworkEvents
| where Timestamp > ago(1d)
| where RemoteUrl has_any ("t.me","telegram.me","telegra.ph","steamcommunity.com","mastodon.social","pastebin.com","paste.ee","ipinfo.io","api.ipify.org","icanhazip.com")
| where InitiatingProcessFileName !in~ ("chrome.exe","msedge.exe","firefox.exe","brave.exe","opera.exe","iexplore.exe","msedgewebview2.exe","Telegram.exe","steam.exe","steamwebhelper.exe")
| summarize Hits = count(), Urls = make_set(RemoteUrl, 20), FirstSeen = min(Timestamp), LastSeen = max(Timestamp)
    by DeviceName, InitiatingProcessFileName, InitiatingProcessFolderPath, InitiatingProcessCommandLine, InitiatingProcessAccountName
| project FirstSeen, LastSeen, DeviceName, InitiatingProcessFileName, InitiatingProcessFolderPath, InitiatingProcessCommandLine, InitiatingProcessAccountName, Hits, Urls
| order by LastSeen desc
```

**Tuning notes:** Allowlist internal monitoring agents that query ipify/ipinfo for public-IP checks, and developer tooling using pastebin. Highest fidelity when the initiating process runs from %TEMP%/%APPDATA%/%PUBLIC% or is unsigned — add that folder filter if volume is high.

## 5) Cobalt Strike Beacon Named Pipe Patterns

**Tactic:** DefenseEvasion  
**ATT&CK:** T1055  
**Severity:** High  
**Purpose:** Cobalt Strike's default and semi-default named pipes (msagent_*, postex_*, status_*, MSSE-*) are created during beacon SMB linking, post-exploitation job execution and process injection. Detecting these pipe names catches beacons independent of C2 infrastructure.

```kusto
DeviceEvents
| where Timestamp > ago(1d)
| where ActionType in ("NamedPipeEvent","NamedPipeCreated","NamedPipeConnected")
| extend PipeName = tostring(parse_json(AdditionalFields).PipeName)
| where isnotempty(PipeName)
| where PipeName matches regex @"(?i)\\(msagent_[0-9a-f]{2,6}|status_[0-9a-f]{2,8}|postex_[0-9a-f]{4,8}|postex_ssh_[0-9a-f]{4,8}|MSSE-[0-9a-f]{3,6}-server|mojo\.5688\.8052\.[0-9]{6,}|interprocess_[0-9]{4,}|wkssvc_[0-9a-f]{4,})$"
| project Timestamp, DeviceName, PipeName, ActionType, InitiatingProcessFileName, InitiatingProcessFolderPath, InitiatingProcessCommandLine, InitiatingProcessParentFileName, InitiatingProcessAccountName, InitiatingProcessSHA256, ReportId
| order by Timestamp desc
```

**Tuning notes:** MSSE-* pipes are also used by legitimate Microsoft AV components — validate the initiating process path and signer. If NamedPipeEvent volume is not onboarded in your tenant, fall back to the beacon spawnto detection. Add newly observed custom malleable-profile pipe names to the regex as they are discovered.

## 6) Local Privilege Escalation Outcome: SYSTEM-Integrity Child Spawned From Medium/Low Integrity Parent

**Tactic:** PrivilegeEscalation  
**ATT&CK:** T1068  
**Severity:** High  
**Purpose:** Exploitation of kernel LPE bugs such as CVE-2026-68820 (afd.sys use-after-free in the Ancillary Function Driver for WinSock) is best detected by its outcome: an unprivileged process suddenly parenting a SYSTEM/High integrity shell or tool.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where ProcessIntegrityLevel in ("System","High")
| where InitiatingProcessIntegrityLevel in ("Medium","Low","Untrusted")
| where AccountName in~ ("system","local service","network service") or ProcessIntegrityLevel == "System"
| where FileName in~ ("cmd.exe","powershell.exe","pwsh.exe","whoami.exe","net.exe","net1.exe","reg.exe","sc.exe","rundll32.exe","wmic.exe","cscript.exe","wscript.exe","mshta.exe","psexesvc.exe","taskmgr.exe")
| where InitiatingProcessFileName !in~ ("consent.exe","services.exe","svchost.exe","wininit.exe","userinit.exe")
| project Timestamp, DeviceName, AccountName, AccountDomain, FileName, ProcessCommandLine, ProcessIntegrityLevel, InitiatingProcessFileName, InitiatingProcessFolderPath, InitiatingProcessCommandLine, InitiatingProcessAccountName, InitiatingProcessIntegrityLevel, InitiatingProcessSHA256, ReportId
| order by Timestamp desc
```

**Tuning notes:** UAC-elevated launches normally show consent.exe lineage and are excluded; verify additional local elevation brokers in your environment (RMM agents, software-center clients, SCCM, patching tools) and allowlist their parent paths/hashes. Correlate hits with recent afd.sys/DeviceEvents driver-load or crash activity and with unsigned binaries executing from user-writable directories.

## 7) Java/Metabase Application Server Spawning OS Command Interpreter

**Tactic:** Execution  
**ATT&CK:** T1190  
**Severity:** High  
**Purpose:** Post-exploitation of CVE-2026-72898 (unauthenticated SQL injection in Metabase leading to admin access and credential theft) typically leads to command execution or reconnaissance under the Java process hosting the application. Detects shell/recon children of java processes.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFileName in~ ("java.exe","javaw.exe","metabase.exe")
| where FileName in~ ("cmd.exe","powershell.exe","pwsh.exe","bash.exe","sh.exe","wsl.exe","cscript.exe","wscript.exe","mshta.exe","rundll32.exe","certutil.exe","curl.exe","bitsadmin.exe","net.exe","net1.exe","whoami.exe","ipconfig.exe","nltest.exe","tasklist.exe","reg.exe","schtasks.exe")
| project Timestamp, DeviceName, AccountName, FileName, ProcessCommandLine, FolderPath, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessAccountName, ProcessIntegrityLevel, ReportId
| order by Timestamp desc
```

**Tuning notes:** Some Java applications legitimately shell out (build agents, Jenkins, ETL jobs, plugin installers). Scope to servers hosting Metabase/internet-facing Java apps via DeviceName or device group, and allowlist known wrapper scripts by command line. Highest fidelity for whoami/net/curl/powershell -enc children.
