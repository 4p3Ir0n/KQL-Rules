## 1) Suspicious Child Process Spawned by TrueConf Server (CVE-2026-72529/72530 Exploitation)

**Tactic:** Execution  
**ATT&CK:** T1190  
**Severity:** High  
**Purpose:** Detects post-exploitation command execution stemming from the TrueConf Server service, which is the observable endpoint artifact of the code-injection / missing-authentication flaws reachable over 4307/TCP that let an attacker break out of the isolated script environment and run arbitrary code on the host.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFileName has "trueconf" or InitiatingProcessFolderPath has "trueconf" or InitiatingProcessParentFileName has "trueconf"
| where FileName in~ ("cmd.exe","powershell.exe","pwsh.exe","wscript.exe","cscript.exe","mshta.exe","rundll32.exe","regsvr32.exe","certutil.exe","curl.exe","bitsadmin.exe","net.exe","net1.exe","whoami.exe","nltest.exe","schtasks.exe","sc.exe","python.exe","node.exe","ftp.exe")
| project Timestamp, DeviceName, AccountDomain, AccountName, InitiatingProcessFileName, InitiatingProcessFolderPath, InitiatingProcessCommandLine, FileName, FolderPath, ProcessCommandLine, ProcessIntegrityLevel, ReportId
```

**Tuning notes:** Validate the exact TrueConf service binary names in your estate (e.g. trueconf_server.exe, tc_server.exe) and pin InitiatingProcessFolderPath to the install path to cut noise. Legitimate TrueConf maintenance scripts or vendor-supplied update routines may spawn cmd.exe/powershell.exe — baseline them for a week and allowlist by exact command line. Consider raising severity when ProcessCommandLine contains encoded payloads or outbound download utilities.

## 2) Inbound External Connections to TrueConf Server Management Port 4307/TCP

**Tactic:** InitialAccess  
**ATT&CK:** T1190  
**Severity:** Medium  
**Purpose:** Surfaces internet-reachable TrueConf Server instances receiving inbound connections on 4307/TCP, the vector for CVE-2026-72529 (missing authentication) and CVE-2026-72530 (code injection), so exposure and possible exploitation attempts can be triaged.

```kusto
DeviceNetworkEvents
| where Timestamp > ago(1d)
| where LocalPort == 4307
| where ActionType in ("InboundConnectionAccepted","ConnectionSuccess","ListeningConnectionCreated")
| where not(ipv4_is_private(RemoteIP)) and RemoteIP !startswith "127." and isnotempty(RemoteIP)
| summarize Attempts = count(), FirstSeen = min(Timestamp), LastSeen = max(Timestamp), RemoteIPs = make_set(RemoteIP, 50) by DeviceName, LocalIP, LocalPort, InitiatingProcessFileName, InitiatingProcessFolderPath
| project FirstSeen, LastSeen, DeviceName, LocalIP, LocalPort, InitiatingProcessFileName, InitiatingProcessFolderPath, Attempts, RemoteIPs
```

**Tuning notes:** Allowlist known federation/partner peer IP ranges and any managed-service scanner (e.g. authorized vulnerability scanners). If TrueConf is intentionally internet-facing, invert the logic and alert only on RemoteIPs outside the approved peer list, or pivot to the companion child-process rule for confirmation of exploitation.

## 3) ClickFix / FakeCaptcha Lure - LOLBIN Launched Directly From Explorer Run Dialog

**Tactic:** Execution  
**ATT&CK:** T1204.004  
**Severity:** High  
**Purpose:** Detects the core ClickFix / ClearFake / IClickFix / OffLoader delivery TTP where a victim is socially engineered to paste an attacker-supplied command into the Windows Run dialog or terminal, causing explorer.exe to spawn powershell.exe, mshta.exe, cmd.exe or curl.exe with a remote download/execute payload. Behavioral, so it survives rotation of the 1000+ fresh C2/payload domains.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFileName =~ "explorer.exe"
| where FileName in~ ("powershell.exe","pwsh.exe","cmd.exe","mshta.exe","wscript.exe","cscript.exe","curl.exe","msiexec.exe","rundll32.exe","regsvr32.exe","conhost.exe","forfiles.exe")
| where ProcessCommandLine has_any ("iwr ","invoke-webrequest","invoke-expression","iex(","iex ","downloadstring","downloadfile","frombase64string","-enc","-ec ","-e ","http://","https://","webclient","start-process","windowstyle hidden","-w h","bitstransfer","certutil","curl ","msiexec /i http","mshta http","Set-Clipboard","clip.exe")
| project Timestamp, DeviceName, AccountDomain, AccountName, FileName, FolderPath, ProcessCommandLine, InitiatingProcessFileName, InitiatingProcessCommandLine, ProcessIntegrityLevel, SHA256, ReportId
```

**Tuning notes:** Developer and IT-admin workstations legitimately launch PowerShell from Explorer; scope out known admin accounts or a device group, and allowlist recurring internal URLs/UNC paths. Highest-fidelity subset is mshta/curl/msiexec with an http(s) argument plus a hidden-window flag — split those into a Critical-severity variant if volume is high.

## 4) ClickFix Run Dialog (RunMRU) Registry Artifact of Pasted Malicious Command

**Tactic:** Execution  
**ATT&CK:** T1059.001  
**Severity:** High  
**Purpose:** Captures the forensic fingerprint of ClickFix-style lures: the attacker's copy-paste command is written to HKCU\...\Explorer\RunMRU when executed from the Win+R dialog. Detects the technique even if the spawned process is missed or obfuscated.

```kusto
DeviceRegistryEvents
| where Timestamp > ago(1d)
| where RegistryKey has @"\Explorer\RunMRU"
| where ActionType in ("RegistryValueSet","RegistryKeyCreated")
| where RegistryValueData has_any ("powershell","pwsh","mshta","curl","certutil","bitsadmin","msiexec","cmd /c","cmd.exe /c","iwr","iex","invoke-","frombase64string","http://","https://","-enc","-w hidden","\\\\")
| project Timestamp, DeviceName, InitiatingProcessAccountDomain, InitiatingProcessAccountName, RegistryKey, RegistryValueName, RegistryValueData, InitiatingProcessFileName, InitiatingProcessCommandLine, ReportId
```

**Tuning notes:** Admins routinely type cmd/powershell into Run; require an http(s) URL, base64 blob, or hidden-window flag in RegistryValueData to reduce false positives. Very long (>150 char) RunMRU values with trailing whitespace padding are a strong ClickFix signal — consider adding strlen() filtering. Allowlist scripted deployment or helpdesk jump hosts.

## 5) Service Installed With Binary in User-Writable Path (CTFLoaderService / Mythic / Covenant Style)

**Tactic:** Persistence  
**ATT&CK:** T1543.003  
**Severity:** Medium  
**Purpose:** Detects the persistence step common to the dropper/loader activity clustered under the fresh 'Unknown malware' indicators (CTFLoaderService, Mythic, Covenant, Diamotrix), where an implant registers a Windows service whose image path resides in a temp, user profile, or public directory, or executes a script interpreter.

```kusto
DeviceEvents
| where Timestamp > ago(1d)
| where ActionType == "ServiceInstalled"
| extend ServiceName = tostring(AdditionalFields.ServiceName), ImagePath = tostring(AdditionalFields.ServiceImagePath), StartType = tostring(AdditionalFields.ServiceStartType)
| where ImagePath has_any (@"\appdata\", @"\temp\", @"\users\public\", @"\programdata\", @"\downloads\", @"\windows\temp\", "powershell", "pwsh", "cmd.exe /c", "rundll32", "mshta", "regsvr32", "-enc", "frombase64string")
| project Timestamp, DeviceName, InitiatingProcessAccountDomain, InitiatingProcessAccountName, ServiceName, ImagePath, StartType, InitiatingProcessFileName, InitiatingProcessFolderPath, InitiatingProcessCommandLine, ReportId
```

**Tuning notes:** Allowlist legitimate agents that install services from ProgramData (EDR, RMM, backup, some VPN clients) by ServiceName and signed ImagePath. Services whose name mimics a Windows component (e.g. CTFLoaderService, WinDefendUpdate) but live outside System32 deserve immediate escalation. Also consider correlating with DeviceProcessEvents for sc.exe create / New-Service command lines.

## 6) AppLocker Policy Enumeration via Get-AppLockerPolicy (Sigma f14b1e99)

**Tactic:** Discovery  
**ATT&CK:** T1518.001  
**Severity:** Low  
**Purpose:** Faithful translation of the Sigma rule: identifies PowerShell (powershell.exe/pwsh.exe) invoking Get-AppLockerPolicy with an -Effective, -Ldap, or -Local scope, indicating an adversary profiling application control before selecting an execution bypass.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where FileName in~ ("powershell.exe","pwsh.exe") or ProcessVersionInfoOriginalFileName in~ ("PowerShell.EXE","pwsh.dll")
| where ProcessCommandLine contains "Get-AppLockerPolicy"
| where ProcessCommandLine matches regex @"(?i)[\s]+[-/–—]{1,2}(Effective|Ldap[\s]|Local)"
| project Timestamp, DeviceName, AccountDomain, AccountName, FileName, ProcessCommandLine, InitiatingProcessFileName, InitiatingProcessCommandLine, ProcessIntegrityLevel, ReportId
```

**Tuning notes:** The regex reproduces Sigma's 'windash' modifier (-, /, en/em dash variants). Application-control engineering teams and compliance scanners legitimately run this cmdlet — allowlist by AccountName or by the specific management host. Escalate when the same session also enumerates WDAC/CI policies or immediately follows with an LOLBIN execution attempt.

## 7) Microsoft Graph PowerShell Bulk Entra ID Enumeration From an Endpoint

**Tactic:** Discovery  
**ATT&CK:** T1526  
**Severity:** Low  
**Purpose:** Hunts for on-host use of Microsoft.Graph / Microsoft.Graph.Beta PowerShell to bulk-enumerate Entra ID users, MFA/authentication methods, sign-in logs, or to authenticate via device-code flow — the same tradecraft described in the ISC diaries and increasingly abused by attackers for cloud recon after an endpoint compromise.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where FileName in~ ("powershell.exe","pwsh.exe") or ProcessVersionInfoOriginalFileName in~ ("PowerShell.EXE","pwsh.dll")
| where ProcessCommandLine has_any ("Connect-MgGraph","Get-MgUser","Get-MgBetaUser","Get-MgUserAuthenticationMethod","Get-MgBetaUserAuthenticationMethod","Get-MgReportAuthenticationMethod","Get-MgAuditLogSignIn","Get-MgBetaReportAuthenticationMethod","Get-MgDirectoryRole")
| where ProcessCommandLine has_any ("-All","UseDeviceAuthentication","-DeviceCode","Export-Csv","Out-File","ConvertTo-Json","-Top 9","AccessToken")
| project Timestamp, DeviceName, AccountDomain, AccountName, FileName, ProcessCommandLine, InitiatingProcessFileName, InitiatingProcessCommandLine, ProcessIntegrityLevel, ReportId
```

**Tuning notes:** Identity administrators run exactly these cmdlets during MFA rollouts — restrict to non-admin accounts or devices outside your privileged-access workstation group, and allowlist scheduled reporting jobs by parent process. Connect-MgGraph with -UseDeviceAuthentication on a user workstation is the highest-signal subset and can be promoted to Medium/High.

## 8) Cloud Instance Metadata Service Access From an ML/Web Application Process (MLflow SSRF CVE-2026-64849)

**Tactic:** Discovery  
**ATT&CK:** T1552.005  
**Severity:** High  
**Purpose:** Detects a server-side request forgery being driven through MLflow or a similar Python/Java web application to reach link-local cloud metadata endpoints (169.254.169.254 and cloud-specific equivalents) to steal instance credentials — the practical impact of CVE-2026-64849.

```kusto
DeviceNetworkEvents
| where Timestamp > ago(1d)
| where RemoteIP in ("169.254.169.254","169.254.170.2","100.100.100.200","192.0.0.192") or RemoteUrl has_any ("metadata.google.internal","169.254.169.254","metadata.azure.com")
| where InitiatingProcessFileName has_any ("python","python3","pythonw","gunicorn","uvicorn","waitress","mlflow","java","node","conda")
   or InitiatingProcessCommandLine has_any ("mlflow","mlflow server","mlflow ui")
| project Timestamp, DeviceName, ActionType, RemoteIP, RemotePort, RemoteUrl, LocalIP, InitiatingProcessFileName, InitiatingProcessFolderPath, InitiatingProcessCommandLine, InitiatingProcessAccountName, ReportId
```

**Tuning notes:** Cloud agents and SDKs legitimately query IMDS; this rule deliberately scopes to app-server interpreters. Allowlist known instrumentation (e.g. boto3 credential refresh inside an approved service account) by process command line, and prefer IMDSv2 enforcement as the real fix. Correlate hits with subsequent outbound connections from the same host indicating credential exfiltration.
