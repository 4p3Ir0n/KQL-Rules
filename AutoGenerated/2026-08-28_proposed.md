## 1) ClickFix / ClearFake: Suspicious Command Pasted into Windows Run Dialog (RunMRU)

**Tactic:** Execution  
**ATT&CK:** T1204.004  
**Severity:** High  
**Purpose:** ClearFake and IClickFix lures instruct victims to copy a command from a fake CAPTCHA/browser-error page and paste it into the Windows Run dialog. Every such execution leaves an entry in the HKCU Explorer\RunMRU registry key, making this one of the most durable detections for the ClickFix delivery pattern.

```kusto
DeviceRegistryEvents
| where Timestamp > ago(1d)
| where RegistryKey has @"\Explorer\RunMRU"
| where isnotempty(RegistryValueData)
| extend Cmd = tolower(RegistryValueData)
| where Cmd has_any ("powershell", "pwsh", "mshta", "cmd /c", "cmd.exe /c", "curl", "certutil", "bitsadmin", "msiexec", "rundll32", "regsvr32", "wscript", "cscript", "conhost", "forfiles", "\\\\")
    or Cmd has_any ("http://", "https://", "frombase64string", "-enc", "-e ", "iex", "invoke-expression", "invoke-restmethod", "invoke-webrequest", "downloadstring", "-w hidden", "-windowstyle hidden", "-nop", "bypass", "\u2705", "i am not a robot", "verification")
| project Timestamp, DeviceId, DeviceName, InitiatingProcessAccountName, RegistryKey, RegistryValueName, RegistryValueData, InitiatingProcessFileName, InitiatingProcessCommandLine, ReportId
```

**Tuning notes:** Legitimate admin use of Run to launch cmd.exe/powershell.exe with no arguments is common — consider requiring the value to contain a URL, encoding artifact, or hidden-window switch before alerting at High. Allowlist known admin accounts / jump hosts and internal UNC paths used by helpdesk scripts. RunMRU values are ordered by an 'MRUList' value; ignore writes to RegistryValueName == 'MRUList'.

## 2) Script Interpreter Spawned Directly by explorer.exe with Download/Encoded Payload

**Tactic:** Execution  
**ATT&CK:** T1059.001  
**Severity:** High  
**Purpose:** Detects the execution stage of ClickFix/ClearFake and similar paste-and-run social engineering: a scripting or LOLBin process launched as a direct child of explorer.exe (Run dialog, desktop, or Explorer address bar) using hidden windows, encoded commands, or remote download cradles.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFileName =~ "explorer.exe"
| where FileName in~ ("powershell.exe", "pwsh.exe", "mshta.exe", "cmd.exe", "curl.exe", "certutil.exe", "bitsadmin.exe", "msiexec.exe", "rundll32.exe", "regsvr32.exe", "wscript.exe", "cscript.exe", "conhost.exe", "forfiles.exe", "mftrace.exe")
| extend Cmd = tolower(ProcessCommandLine)
| where Cmd has_any ("-w hidden", "-windowstyle hidden", "-enc", "-ec ", "-encodedcommand", "frombase64string", "iex", "invoke-expression", "invoke-webrequest", "invoke-restmethod", "irm ", "iwr ", "downloadstring", "downloadfile", "start-bitstransfer", "http://", "https://", "-nop", "-noni", "executionpolicy bypass", "urlcache", "/i http", "msxml2.xmlhttp", "scripting.filesystemobject")
| project Timestamp, DeviceId, DeviceName, AccountName, FileName, ProcessCommandLine, FolderPath, SHA256, InitiatingProcessFileName, InitiatingProcessCommandLine, ReportId
```

**Tuning notes:** IT self-service scripts and software deployment run from Explorer can match; allowlist by signed script paths, specific SHA256, or admin account. If noisy, require two or more of the suspicious tokens or exclude internal HTTP hosts (intranet, SCCM/WSUS FQDNs). conhost.exe as a child of explorer.exe with a command line is inherently unusual and should stay in scope.

## 3) EtherHiding: Scripting Host or LOLBin Connecting to Public Blockchain RPC Endpoints

**Tactic:** CommandAndControl  
**ATT&CK:** T1102  
**Severity:** High  
**Purpose:** ClearFake/IClickFix use 'EtherHiding' — retrieving the next-stage payload or C2 configuration from smart contracts via public blockchain RPC nodes. Non-browser processes (PowerShell, mshta, curl, wscript) talking to Ethereum/BSC RPC providers is a strong campaign indicator.

```kusto
DeviceNetworkEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFileName in~ ("powershell.exe", "pwsh.exe", "mshta.exe", "wscript.exe", "cscript.exe", "curl.exe", "certutil.exe", "rundll32.exe", "regsvr32.exe", "msiexec.exe", "node.exe", "conhost.exe")
| extend Target = tolower(strcat(RemoteUrl, " ", RemoteIP))
| where Target has_any ("bsc-dataseed", "binance.org", "cloudflare-eth.com", "mainnet.infura.io", "rpc.ankr.com", "publicnode.com", "llamarpc.com", "drpc.org", "alchemyapi.io", "g.alchemy.com", "blockpi.network", "nodereal.io", "1rpc.io", "etherscan.io", "bscscan.com", "blastapi.io", "omniatech.io")
| summarize Connections = count(), Targets = make_set(RemoteUrl, 20), Ports = make_set(RemotePort, 10), FirstSeen = min(Timestamp), LastSeen = max(Timestamp) by DeviceId, DeviceName, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessAccountName
| project FirstSeen, LastSeen, DeviceId, DeviceName, InitiatingProcessAccountName, InitiatingProcessFileName, InitiatingProcessCommandLine, Connections, Targets, Ports
```

**Tuning notes:** Allowlist developer and blockchain-analytics workstations (by device group) and legitimate node.exe/web3 tooling. Extend the RPC provider list as new public nodes appear; consider also flagging any process resolving *.eth or ENS gateways. Browser processes are intentionally excluded to reduce noise from legitimate wallet extensions.

## 4) Web Server Process Writing Script or Disguised Payload Files into Web Root

**Tactic:** Persistence  
**ATT&CK:** T1505.003  
**Severity:** High  
**Purpose:** php.shin_webshell is deployed onto compromised WordPress sites (wp-admin/wp-content paths, .gif-disguised PHP). Detects the web server or PHP runtime creating executable script content in web-accessible directories — the core webshell installation behavior.

```kusto
DeviceFileEvents
| where Timestamp > ago(1d)
| where ActionType in ("FileCreated", "FileModified", "FileRenamed")
| where InitiatingProcessFileName in~ ("w3wp.exe", "php.exe", "php-cgi.exe", "php-fpm", "httpd", "httpd.exe", "apache2", "nginx", "java", "tomcat", "caddy", "lighttpd")
| extend Path = tolower(FolderPath)
| where Path has_any ("wp-content", "wp-admin", "wp-includes", "/uploads/", "\\uploads\\", "/htdocs/", "\\wwwroot\\", "/www/", "/public_html/", "/var/www/", "/webapps/", "/plugins/", "/themes/")
| where Path endswith ".php" or Path endswith ".php5" or Path endswith ".php7" or Path endswith ".phtml" or Path endswith ".phar" or Path endswith ".inc" or Path endswith ".jsp" or Path endswith ".jspx" or Path endswith ".aspx" or Path endswith ".ashx" or Path endswith ".gif" or Path endswith ".ico" or Path endswith ".txt"
| project Timestamp, DeviceId, DeviceName, ActionType, FileName, FolderPath, SHA256, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessAccountName, ReportId
```

**Tuning notes:** CMS auto-updates and plugin installs legitimately write PHP into wp-content — allowlist update windows, the WordPress cron/updater user, and known deployment pipelines (CI agents, rsync). Media uploads make .gif/.ico noisy: consider restricting image extensions to files created outside /uploads/ or correlate with a subsequent process spawn from the same web server (see the web-server-spawns-shell rule).

## 5) Web Application Server Spawning Command Shell or Recon Utility

**Tactic:** InitialAccess  
**ATT&CK:** T1190  
**Severity:** Critical  
**Purpose:** Generic, durable post-exploitation detection covering AjaxPro .NET deserialization RCE (CVE-2021-23758), webshell command execution (php.shin_webshell), and exploitation of internet-facing services such as ownCloud and JFrog Artifactory: the application server process spawns an interactive shell or discovery/download tooling.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFileName in~ ("w3wp.exe", "aspnet_wp.exe", "php.exe", "php-cgi.exe", "php-fpm", "httpd", "httpd.exe", "apache2", "nginx", "java", "javaw.exe", "tomcat", "node.exe", "caddy")
| where FileName in~ ("cmd.exe", "powershell.exe", "pwsh.exe", "bash", "sh", "dash", "zsh", "python", "python3", "perl", "whoami.exe", "whoami", "net.exe", "net1.exe", "nltest.exe", "ipconfig.exe", "systeminfo.exe", "certutil.exe", "bitsadmin.exe", "curl", "curl.exe", "wget", "nc", "ncat", "socat", "id", "uname", "reg.exe", "rundll32.exe", "cscript.exe", "wscript.exe")
| project Timestamp, DeviceId, DeviceName, AccountName, AccountDomain, FileName, ProcessCommandLine, FolderPath, SHA256, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessAccountName, ReportId
```

**Tuning notes:** Some applications legitimately shell out (build agents, Artifactory plugins, PHP exec() in monitoring scripts, Jenkins on Tomcat). Baseline per-server: allowlist specific parent command lines or child command-line patterns rather than removing whole binaries. Treat java/node parents on CI infrastructure as a separate lower-severity stream. Highest fidelity when the child command line contains encoding, download cradles, or reverse-shell syntax (e.g. 'bash -i >& /dev/tcp').

## 6) Artifactory/Java Service Writing Files Outside Its Data Directory (Path Traversal)

**Tactic:** InitialAccess  
**ATT&CK:** T1190  
**Severity:** High  
**Purpose:** CVE-2026-66384 lets an authenticated user write data outside the intended Docker cache path in JFrog Artifactory. Detects the Artifactory/Java service account creating files in sensitive or code-execution-capable locations, indicating successful path-traversal write.

```kusto
DeviceFileEvents
| where Timestamp > ago(1d)
| where ActionType in ("FileCreated", "FileModified", "FileRenamed")
| where InitiatingProcessFileName in~ ("java", "java.exe", "javaw.exe", "artifactory", "tomcat")
| extend Path = tolower(FolderPath)
| where Path has_any ("/etc/cron", "/etc/passwd", "/etc/shadow", "/etc/sudoers", "/etc/systemd", "/etc/profile.d", "/root/.ssh", "/.ssh/authorized_keys", "/var/spool/cron", "/usr/local/bin", "/usr/bin", "/tmp/", "/dev/shm", "webapps", "\\startup\\", "\\system32\\tasks", "\\programdata\\")
    or Path has_any ("..%2f", "../", "..\\")
| where Path !has "/var/opt/jfrog/artifactory/data/cache"
| project Timestamp, DeviceId, DeviceName, ActionType, FileName, FolderPath, SHA256, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessAccountName, ReportId
```

**Tuning notes:** Java processes write extensively to /tmp and their own work directories — allowlist the specific Artifactory temp/work paths and any application server 'webapps' deploy directory used by legitimate releases, or narrow the rule to devices in the Artifactory device group. Pair with the web-server-spawns-shell rule to confirm exploitation.

## 7) ownCloud/WebDAV Server: Anomalous Bulk File Access or Script Write by Web Service Account

**Tactic:** Collection  
**ATT&CK:** T1213  
**Severity:** Medium  
**Purpose:** CVE-2023-49105 allows unauthenticated access, modification, and deletion of any user's files in ownCloud via WebDAV when the username is known. Detects the resulting behavior on the server: the web/PHP service account touching an unusually large number of user data files, or writing executable script content into the ownCloud tree.

```kusto
DeviceFileEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFileName in~ ("php", "php.exe", "php-fpm", "php-cgi.exe", "httpd", "apache2", "nginx", "w3wp.exe")
| extend Path = tolower(FolderPath)
| where Path has_any ("owncloud", "/data/files/", "nextcloud")
| extend ScriptWrite = (Path endswith ".php" or Path endswith ".phtml" or Path endswith ".sh" or Path endswith ".aspx")
| summarize FilesTouched = dcount(FolderPath), Deletes = countif(ActionType == "FileDeleted"), Modifies = countif(ActionType in ("FileCreated", "FileModified", "FileRenamed")), ScriptWrites = countif(ScriptWrite), SamplePaths = make_set(FolderPath, 15), FirstSeen = min(Timestamp), LastSeen = max(Timestamp)
    by bin(Timestamp, 15m), DeviceId, DeviceName, InitiatingProcessFileName, InitiatingProcessAccountName
| where ScriptWrites > 0 or FilesTouched > 200 or Deletes > 50
| project FirstSeen, LastSeen, DeviceId, DeviceName, InitiatingProcessAccountName, InitiatingProcessFileName, FilesTouched, Modifies, Deletes, ScriptWrites, SamplePaths
```

**Tuning notes:** Thresholds (200 files / 50 deletes per 15 minutes) must be baselined per deployment — busy sync servers exceed this normally; raise until only outliers remain, or scope to off-hours. Exclude scheduled maintenance/cron jobs (occ commands, previews generation, trashbin cleanup). Script writes into the data tree should remain alert-worthy at any volume.

## 8) Linux: Unprivileged Process Obtains Root Shell Without sudo/su (Kernel Exploit Pattern)

**Tactic:** PrivilegeEscalation  
**ATT&CK:** T1068  
**Severity:** High  
**Purpose:** CVE-2026-53362 is a Linux kernel privilege escalation in the IPv6 networking subsystem. Kernel exploits typically end with a root-owned shell or command spawned from a non-root parent, bypassing the normal sudo/su/pkexec chain.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where DeviceId in ((DeviceProcessEvents | where Timestamp > ago(7d) | where FileName in~ ("bash","sh","dash") | distinct DeviceId))
| where FileName in~ ("bash", "sh", "dash", "zsh", "ksh", "python", "python3", "perl", "id", "chattr", "passwd", "useradd", "usermod")
| where AccountName == "root"
| where InitiatingProcessAccountName !in~ ("root", "system")
| where InitiatingProcessFileName !in~ ("sudo", "su", "pkexec", "sshd", "systemd", "cron", "crond", "login", "gdm-session-worker", "runc", "containerd-shim", "dockerd", "doas")
| project Timestamp, DeviceId, DeviceName, AccountName, ProcessId, FileName, ProcessCommandLine, FolderPath, SHA256, InitiatingProcessAccountName, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessId, ReportId
```

**Tuning notes:** Setuid helpers and container runtimes are the main false-positive sources — extend the parent allowlist with site-specific agents (monitoring, backup, CI runners, ansible). The prefilter subquery simply limits scope to Linux devices; replace with a device-group filter if available. Correlate with concurrent 'unshare --map-root-user' / 'ip -6' activity or a recent kernel oops for higher confidence.

## 9) Linux: User Namespace Creation Combined with IPv6/Network Configuration by Non-Root User

**Tactic:** PrivilegeEscalation  
**ATT&CK:** T1068  
**Severity:** Medium  
**Purpose:** Exploits for kernel networking-subsystem flaws (such as the IPv6 privilege escalation in CVE-2026-53362) commonly create an unprivileged user namespace (unshare --map-root-user / clone with CLONE_NEWUSER+CLONE_NEWNET) and then manipulate IPv6 sockets or interfaces to trigger the bug.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| extend Cmd = tolower(ProcessCommandLine)
| where (FileName in~ ("unshare", "nsenter", "newuidmap", "newgidmap") and Cmd has_any ("--map-root-user", "-r", "--net", "-n", "--user", "-u"))
    or (FileName in~ ("ip", "ip6tables", "sysctl", "setcap") and Cmd has_any ("-6", "inet6", "ipv6", "netns add", "net.ipv6"))
| where InitiatingProcessAccountName !in~ ("root", "system")
| summarize Commands = make_set(ProcessCommandLine, 20), Binaries = make_set(FileName, 10), Events = count(), FirstSeen = min(Timestamp), LastSeen = max(Timestamp)
    by DeviceId, DeviceName, AccountName, InitiatingProcessAccountName, InitiatingProcessFileName, InitiatingProcessId
| where array_length(Binaries) > 1 or Events > 3
| project FirstSeen, LastSeen, DeviceId, DeviceName, AccountName, InitiatingProcessAccountName, InitiatingProcessFileName, Binaries, Events, Commands
```

**Tuning notes:** Rootless containers (podman, docker rootless, bubblewrap, flatpak, snap) legitimately use unshare/newuidmap — allowlist those parent processes and the accounts that run them. Network engineers scripting 'ip -6' will match; scope to server device groups or require the unshare and network-configuration components to occur from the same process tree within a short window.

## 10) HTML/SVG Attachment Delivered by Mail Then Opened from Downloads Folder

**Tactic:** InitialAccess  
**ATT&CK:** T1566.001  
**Severity:** Medium  
**Purpose:** Polymorphic phishing pages are increasingly shipped as self-contained HTML/SVG attachments that render a credential-harvesting form locally, evading URL reputation. Detects local execution of such files from browser/mail download locations on the endpoint.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFileName in~ ("outlook.exe", "olk.exe", "winmail.exe", "explorer.exe", "thunderbird.exe", "chrome.exe", "msedge.exe", "firefox.exe", "7zfm.exe", "winrar.exe")
| where FileName in~ ("chrome.exe", "msedge.exe", "firefox.exe", "iexplore.exe", "mshta.exe", "wscript.exe")
| extend Cmd = tolower(ProcessCommandLine)
| where Cmd has_any (".html", ".htm", ".shtml", ".svg", ".xhtml", ".hta")
| where Cmd has_any ("\\downloads\\", "\\temp\\", "\\appdata\\local\\microsoft\\windows\\inetcache", "\\content.outlook\\", "\\temporary internet files\\", "\\appdata\\roaming\\thunderbird")
| project Timestamp, DeviceId, DeviceName, AccountName, FileName, ProcessCommandLine, InitiatingProcessFileName, InitiatingProcessCommandLine, ReportId
```

**Tuning notes:** Users open legitimate downloaded HTML reports (invoices, BI exports) — reduce noise by joining to EmailAttachmentInfo/EmailEvents for external senders, by excluding known internal report filenames, or by requiring the file to have been created within the last hour. mshta.exe or wscript.exe opening these paths should be treated as High regardless of extension.
