## 1) PaperCut NG/MF Server Process Spawning Command Shell or Script Interpreter

**Tactic:** Execution  
**ATT&CK:** T1190  
**Severity:** High  
**Purpose:** Detects post-exploitation of CVE-2026-81578 / CVE-2026-82078 (unauthenticated config modification chained with unsafe reflection RCE) where the PaperCut application server (Java) process spawns an OS command shell, script host, or living-off-the-land download utility.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFileName in~ ("pc-app.exe","pc-service.exe","pc-web-print.exe","java.exe","javaw.exe","pc-client.exe")
| where InitiatingProcessFolderPath has "papercut" or InitiatingProcessCommandLine has "papercut" or InitiatingProcessCommandLine has "pc-app"
| where FileName in~ ("cmd.exe","powershell.exe","pwsh.exe","wscript.exe","cscript.exe","mshta.exe","rundll32.exe","regsvr32.exe","certutil.exe","bitsadmin.exe","curl.exe","net.exe","net1.exe","whoami.exe","nltest.exe","schtasks.exe","bash.exe","sh.exe","wmic.exe")
| project Timestamp, DeviceName, AccountName, FileName, ProcessCommandLine, FolderPath, InitiatingProcessFileName, InitiatingProcessFolderPath, InitiatingProcessCommandLine, InitiatingProcessAccountName, ReportId
```

**Tuning notes:** PaperCut legitimately shells out for some print scripts and health checks (e.g., cmd.exe running 'net view' or printer driver installs) — baseline the normal child commands per print server and allowlist by exact command line, not by parent process. Broaden InitiatingProcessFileName if your deployment uses a wrapper service name. Consider raising severity when the child is powershell with encoded/hidden flags.

## 2) PaperCut Server Process Writing Executable or Script Content

**Tactic:** Persistence  
**ATT&CK:** T1505.003  
**Severity:** High  
**Purpose:** Detects the PaperCut Java server process writing new JAR/JSP/script/binary files to disk, which is the typical outcome of the CVE-2026-82078 unsafe-reflection chain used to stage attacker-controlled bytecode or a web shell on the classpath.

```kusto
DeviceFileEvents
| where Timestamp > ago(1d)
| where ActionType in ("FileCreated","FileModified","FileRenamed")
| where InitiatingProcessFileName in~ ("pc-app.exe","pc-service.exe","java.exe","javaw.exe","pc-web-print.exe")
| where InitiatingProcessFolderPath has "papercut" or InitiatingProcessCommandLine has "papercut"
| where FileName endswith ".jar" or FileName endswith ".jsp" or FileName endswith ".class" or FileName endswith ".war" or FileName endswith ".exe" or FileName endswith ".dll" or FileName endswith ".ps1" or FileName endswith ".bat" or FileName endswith ".vbs" or FileName endswith ".js"
| project Timestamp, DeviceName, FileName, FolderPath, SHA256, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessAccountName, ReportId
```

**Tuning notes:** PaperCut upgrades and plugin deployments legitimately write .jar/.class files — exclude the vendor update process/installer path and known maintenance windows. Tighten by excluding the product's own 'server/lib' and temp extraction directories after baselining, and keep alerting on writes into web-served directories.

## 3) Web Server or PHP Interpreter Spawning Shell / Discovery Commands (Web Shell Activity)

**Tactic:** Execution  
**ATT&CK:** T1505.003  
**Severity:** High  
**Purpose:** Detects php.shin_webshell-style PHP web shell execution (WordPress wp-admin/uploads drops, .gif-disguised payloads) by alerting when a web server or PHP process spawns a command shell, script host, or reconnaissance utility.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFileName in~ ("php.exe","php-cgi.exe","httpd.exe","nginx.exe","w3wp.exe","tomcat.exe","caddy.exe","node.exe")
| where FileName in~ ("cmd.exe","powershell.exe","pwsh.exe","whoami.exe","net.exe","net1.exe","ipconfig.exe","systeminfo.exe","tasklist.exe","certutil.exe","bitsadmin.exe","curl.exe","wget.exe","nltest.exe","arp.exe","reg.exe","schtasks.exe","wmic.exe","bash.exe","sh.exe")
```

**Tuning notes:** Some CMS/plugin functionality (image processing, backup jobs, composer) legitimately shells out — allowlist by full child command line and specific application pool identity. On Linux-based web servers use the equivalent MDE for Linux telemetry (same table) and add 'sh'/'dash' parents. Correlate with outbound connections to *.workers.dev, which this family uses for C2 fronting.

## 4) PHP Web Shell File Written into Web Root by Web Server Process

**Tactic:** Persistence  
**ATT&CK:** T1505.003  
**Severity:** Medium  
**Purpose:** Detects the drop of new PHP files (including double-extension/.gif-masquerading payloads) into WordPress and other web-root directories by a web server or PHP process — the installation step for php.shin_webshell.

```kusto
DeviceFileEvents
| where Timestamp > ago(1d)
| where ActionType in ("FileCreated","FileModified","FileRenamed")
| where InitiatingProcessFileName in~ ("php.exe","php-cgi.exe","httpd.exe","nginx.exe","w3wp.exe","tomcat.exe","node.exe")
| where FolderPath has_any ("wp-content","wp-admin","wp-includes","wwwroot","htdocs","inetpub","httpdocs","public_html","uploads")
| where FileName endswith ".php" or FileName endswith ".phtml" or FileName endswith ".php5" or FileName endswith ".php7" or FileName has ".php." or FileName endswith ".gif.php"
| project Timestamp, DeviceName, FileName, FolderPath, SHA256, FileSize, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessAccountName, ReportId
```

**Tuning notes:** WordPress/plugin auto-updates create many .php files — exclude update paths (wp-content/upgrade, wp-content/plugins/<name> during known maintenance) or suppress bursts by grouping on InitiatingProcessId with a count threshold. Highest fidelity when the write lands in an uploads directory, which should never contain executable PHP.

## 5) Non-Browser Process Loading Browser/NSS Credential DLLs (Vidar Stealer Behavior)

**Tactic:** CredentialAccess  
**ATT&CK:** T1555.003  
**Severity:** High  
**Purpose:** Detects Vidar and similar infostealers that drop and side-load legitimate Mozilla/NSS libraries (nss3.dll, freebl3.dll, softokn3.dll, mozglue.dll, vcruntime140.dll) into their own process to decrypt saved browser credentials, without touching perishable hashes or C2 domains.

```kusto
DeviceImageLoadEvents
| where Timestamp > ago(1d)
| where FileName in~ ("nss3.dll","freebl3.dll","softokn3.dll","mozglue.dll","msvcp140.dll","vcruntime140.dll","sqlite3.dll")
| where InitiatingProcessFileName !in~ ("firefox.exe","thunderbird.exe","chrome.exe","msedge.exe","brave.exe","opera.exe","waterfox.exe","palemoon.exe","seamonkey.exe")
| where InitiatingProcessFolderPath has_any ("\\users\\","\\appdata\\","\\temp\\","\\programdata\\","\\public\\")
| summarize LoadedDlls = make_set(FileName), FirstSeen = min(Timestamp), LastSeen = max(Timestamp) by DeviceName, InitiatingProcessFileName, InitiatingProcessFolderPath, InitiatingProcessCommandLine, InitiatingProcessSHA256, InitiatingProcessAccountName
| where array_length(LoadedDlls) >= 2
| project FirstSeen, LastSeen, DeviceName, InitiatingProcessAccountName, InitiatingProcessFileName, InitiatingProcessFolderPath, InitiatingProcessCommandLine, InitiatingProcessSHA256, LoadedDlls
```

**Tuning notes:** Legitimate apps that embed NSS/sqlite (some VPN clients, password managers, Electron apps, installers running from %TEMP%) will match — allowlist by signer/SHA256 of the initiating process. Lower the array_length threshold to 1 for hunting; raise to 3 to cut noise. Pair with DeviceNetworkEvents for the same process to confirm exfil.

## 6) Command-Line Copy or Query of Browser Credential and Wallet Stores

**Tactic:** CredentialAccess  
**ATT&CK:** T1555.003  
**Severity:** Medium  
**Purpose:** Detects stealer staging behavior (Vidar, ClearFake payloads) where LOLBins or scripts copy browser 'Login Data'/'Cookies' SQLite databases, Local State keys, or crypto-wallet directories prior to exfiltration.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where FileName in~ ("cmd.exe","powershell.exe","pwsh.exe","esentutl.exe","robocopy.exe","xcopy.exe","wscript.exe","cscript.exe","mshta.exe","curl.exe","tar.exe","7z.exe","rar.exe")
| where ProcessCommandLine has_any ("Login Data","Web Data","Local State","cookies.sqlite","logins.json","key4.db","key3.db","Network\\Cookies","wallet.dat","Exodus\\exodus.wallet","Ethereum\\keystore","Local Extension Settings")
| project Timestamp, DeviceName, AccountName, FileName, ProcessCommandLine, FolderPath, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessFolderPath, ReportId
```

**Tuning notes:** Backup software, browser-profile migration tools, and IT scripts can match — allowlist by initiating process path and signer. Add your organization's browser install locations if custom. Investigate any match where the initiating process runs from %TEMP%, %APPDATA%, or was spawned by a script host.

## 7) ClickFix / ClearFake: Malicious Command Pasted into Windows Run Dialog (RunMRU)

**Tactic:** Execution  
**ATT&CK:** T1204.004  
**Severity:** High  
**Purpose:** Detects the ClearFake/ClickFix social-engineering technique where a compromised website instructs the victim to paste a command into the Run dialog; the pasted string is persisted under the RunMRU registry key.

```kusto
DeviceRegistryEvents
| where Timestamp > ago(1d)
| where RegistryKey has "\\Explorer\\RunMRU"
| where ActionType in ("RegistryValueSet","RegistryKeyCreated")
| where RegistryValueData has_any ("powershell","pwsh","mshta","curl","certutil","bitsadmin","msiexec","rundll32","conhost","wscript","cscript","cmd /c","cmd.exe /c","iex","invoke-expression","frombase64string","-enc","-w h","hidden","http://","https://","\\\\")
| project Timestamp, DeviceName, InitiatingProcessAccountName, RegistryKey, RegistryValueName, RegistryValueData, InitiatingProcessFileName, InitiatingProcessCommandLine, ReportId
```

**Tuning notes:** Admins and power users legitimately run UNC paths and cmd from the Run dialog — filter on privileged/IT accounts or require the value to contain a URL, base64, or hidden-window flag. Very low volume in most environments; treat any powershell/mshta with an http(s) URL as high confidence.

## 9) MSHTA or Script Host Executing Remote/Obfuscated Content (Guildma/Astaroth Loader)

**Tactic:** Execution  
**ATT&CK:** T1218.005  
**Severity:** High  
**Purpose:** Detects the Guildma (Astaroth) infection chain delivered via Brazilian Portuguese phishing: LNK/ZIP-delivered scripts invoking mshta.exe against a remote URL or javascript: handler, and wscript/cscript running scripts from user-writable directories.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where (FileName =~ "mshta.exe" and ProcessCommandLine has_any ("http://","https://","javascript:","vbscript:","\\\\"))
    or (FileName in~ ("wscript.exe","cscript.exe") and ProcessCommandLine has_any (".js",".jse",".vbs",".vbe",".wsf") and ProcessCommandLine has_any ("\\appdata\\","\\temp\\","\\public\\","\\programdata\\","\\downloads\\","\\users\\"))
| where InitiatingProcessFileName in~ ("explorer.exe","winrar.exe","7zfm.exe","7zg.exe","outlook.exe","chrome.exe","msedge.exe","firefox.exe","cmd.exe","powershell.exe","wscript.exe","cscript.exe","mshta.exe","winzip32.exe","opera.exe")
| project Timestamp, DeviceName, AccountName, FileName, ProcessCommandLine, FolderPath, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessFolderPath, ReportId
```

**Tuning notes:** Legacy line-of-business apps sometimes use HTA/VBS from user profiles — allowlist by full script path and hash. Guildma also abuses signed LOLBins (bitsadmin, curl, ExtExport-style DLL loads) writing to C:\Users\Public — consider a companion query on DeviceFileEvents for that path. Enrich with EmailEvents to confirm a Portuguese-language lure.

## 11) NTDS.dit / Domain Controller Credential Dumping Attempt

**Tactic:** CredentialAccess  
**ATT&CK:** T1003.003  
**Severity:** Critical  
**Purpose:** Detects the objective stage of the Spring Ring campaign (and most hands-on-keyboard intrusions) where operators reach a domain controller and dump the Active Directory database via ntdsutil, esentutl, vssadmin shadow copies, or DSInternals.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where (FileName in~ ("ntdsutil.exe","dsdbutil.exe") and ProcessCommandLine has_any ("ifm","create full","activate instance ntds"))
    or (ProcessCommandLine has "ntds.dit")
    or (FileName =~ "esentutl.exe" and ProcessCommandLine has_any ("/y","/vss","ntds"))
    or (FileName =~ "vssadmin.exe" and ProcessCommandLine has "create shadow")
    or (FileName in~ ("powershell.exe","pwsh.exe") and ProcessCommandLine has_any ("Get-ADDBAccount","ntdsutil","Copy-VSS","Invoke-NinjaCopy"))
    or (FileName =~ "reg.exe" and ProcessCommandLine has "save" and ProcessCommandLine has_any ("hklm\\sam","hklm\\system","hklm\\security"))
| project Timestamp, DeviceName, AccountName, AccountDomain, FileName, ProcessCommandLine, FolderPath, ProcessIntegrityLevel, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessAccountName, ReportId
```

**Tuning notes:** Scheduled AD backup solutions use ntdsutil IFM and VSS — allowlist the backup service account plus its parent process and expected schedule. Any match originating from an interactive session, a non-DC host, or a process parented by a browser/Teams/RMM tool should be treated as critical.
