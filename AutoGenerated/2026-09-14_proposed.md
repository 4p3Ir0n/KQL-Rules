## 1) ScreenConnect Remote Access Tool Spawning Script Interpreters or LOLBins

**Tactic:** Execution  
**ATT&CK:** T1059.001  
**Severity:** High  
**Purpose:** Detects post-exploitation of ConnectWise ScreenConnect (CVE-2026-84869) where an unauthorized file transfer/command execution through an active remote session results in ScreenConnect client/service processes spawning interpreters, LOLBins or dropped executables.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFileName has_any ("ScreenConnect.ClientService.exe", "ScreenConnect.WindowsClient.exe", "ScreenConnect.WindowsBackstageShell.exe", "ScreenConnect.Service.exe", "connectwisecontrol.client.exe")
| where FileName in~ ("cmd.exe", "powershell.exe", "pwsh.exe", "wscript.exe", "cscript.exe", "mshta.exe", "rundll32.exe", "regsvr32.exe", "certutil.exe", "bitsadmin.exe", "curl.exe", "msiexec.exe", "net.exe", "net1.exe", "whoami.exe", "nltest.exe", "reg.exe", "schtasks.exe", "bcdedit.exe", "vssadmin.exe", "wmic.exe")
    or ProcessCommandLine has_any ("-enc ", "-EncodedCommand", "FromBase64String", "DownloadString", "Invoke-WebRequest", "IEX(", "Hidden")
| project Timestamp, DeviceName, AccountName, AccountDomain, InitiatingProcessFileName, InitiatingProcessCommandLine, FileName, ProcessCommandLine, FolderPath, SHA256, ReportId
```

**Tuning notes:** Legitimate helpdesk technicians routinely run cmd/powershell via ScreenConnect. Baseline by approved technician accounts, expected remote-support hours, and known administrative scripts. Consider suppressing benign one-liners (e.g., 'net use' to known shares) and alert-uplift when the spawned child is an executable written to %TEMP%, %PUBLIC%, or %ProgramData% within the prior 10 minutes.

## 2) Unauthorized ScreenConnect Client Installation or Temporary Session Binary Drop

**Tactic:** Persistence  
**ATT&CK:** T1543.003  
**Severity:** Medium  
**Purpose:** Detects attacker-driven deployment of ScreenConnect clients (or file transfer staging in the ScreenConnect temp/session folders) which is the typical outcome of abusing CVE-2026-84869 and of RMM-based intrusions.

```kusto
DeviceFileEvents
| where Timestamp > ago(1d)
| where (FolderPath has_any (@"\ScreenConnect\", @"\ConnectWiseControl\", @"ScreenConnect Client") and FileName endswith ".exe" or FileName endswith ".msi" or FileName endswith ".ps1" or FileName endswith ".bat" or FileName endswith ".dll")
    or (FileName matches regex @"(?i)^ScreenConnect\.ClientSetup.*\.(exe|msi)$")
| where InitiatingProcessFileName !in~ ("msiexec.exe")
    or InitiatingProcessFileName has_any ("ScreenConnect.ClientService.exe", "ScreenConnect.WindowsClient.exe", "ScreenConnect.WindowsBackstageShell.exe")
| project Timestamp, DeviceName, InitiatingProcessAccountName, InitiatingProcessFileName, InitiatingProcessCommandLine, FileName, FolderPath, SHA256, ActionType, ReportId
```

**Tuning notes:** If ScreenConnect is a sanctioned RMM in your environment, allowlist the organization's instance ID / signed setup file names and the deploying management server. Highest fidelity on endpoints where ScreenConnect is NOT part of the standard build — maintain an asset list of approved RMM hosts.

## 3) ClickFix / ClearFake: Browser-Spawned Shell Executing Clipboard Paste Payload

**Tactic:** Execution  
**ATT&CK:** T1204.004  
**Severity:** High  
**Purpose:** Detects the ClickFix and ClearFake social-engineering chain where a user is told to paste a command into the Run dialog or terminal, producing a browser/explorer-parented powershell, mshta, curl or conhost process with download-and-execute command lines.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFileName in~ ("explorer.exe", "chrome.exe", "msedge.exe", "firefox.exe", "brave.exe", "opera.exe", "iexplore.exe")
| where FileName in~ ("powershell.exe", "pwsh.exe", "cmd.exe", "mshta.exe", "wscript.exe", "cscript.exe", "curl.exe", "certutil.exe", "msiexec.exe", "conhost.exe")
| where ProcessCommandLine has_any ("FromBase64String", "-enc ", "-EncodedCommand", "DownloadString", "DownloadFile", "Invoke-RestMethod", "Invoke-WebRequest", "iwr ", "irm ", "iex", "curl ", "Start-BitsTransfer", "mshta http", "msiexec /i http", "bitsadmin", "mshta.exe http", "Set-Clipboard", "clipboard")
    or ProcessCommandLine matches regex @"(?i)(hidden|bypass)\s" and ProcessCommandLine has "http"
| project Timestamp, DeviceName, AccountName, InitiatingProcessFileName, InitiatingProcessCommandLine, FileName, ProcessCommandLine, FolderPath, SHA256, ReportId
```

**Tuning notes:** Explorer-parented PowerShell is common for admins; restrict to non-admin users or add a 'user is not in IT OU' condition. Allowlist internal update scripts and known software installers launched from browser downloads. A strong enrichment is checking for a preceding DeviceEvents 'ClipboardCopy'-like activity or RunMRU registry write within 2 minutes.

## 4) Suspicious Command Written to Explorer RunMRU (ClickFix Run Dialog Paste)

**Tactic:** Execution  
**ATT&CK:** T1204.004  
**Severity:** Medium  
**Purpose:** ClickFix lures instruct victims to press Win+R and paste an attacker command; Windows records the pasted string under HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\RunMRU. Detects script-interpreter or download commands recorded there.

```kusto
DeviceRegistryEvents
| where Timestamp > ago(1d)
| where ActionType in ("RegistryValueSet", "RegistryKeyCreated")
| where RegistryKey has @"\Explorer\RunMRU"
| where RegistryValueData has_any ("powershell", "pwsh", "cmd /c", "cmd.exe /c", "mshta", "curl ", "certutil", "msiexec", "wscript", "cscript", "rundll32", "bitsadmin", "http://", "https://", "FromBase64String", "-enc", "iex", "irm ", "iwr ")
| project Timestamp, DeviceName, InitiatingProcessAccountName, RegistryKey, RegistryValueName, RegistryValueData, InitiatingProcessFileName, ReportId
```

**Tuning notes:** Administrators legitimately type 'cmd', 'powershell' or UNC paths into Run — require the value to also contain a URL, base64 marker or encoded flag for high-fidelity alerting, and allowlist IT/admin accounts. Note that RunMRU values append a trailing '\1' character.

## 5) AsyncRAT Behavior: .NET Payload in User-Writable Path Beaconing on Non-Standard Ports

**Tactic:** CommandAndControl  
**ATT&CK:** T1571  
**Severity:** High  
**Purpose:** Detects AsyncRAT-style implants: an executable running from %AppData%, %Temp%, %ProgramData% or %Public% making repeated outbound connections to uncommon high ports typical of AsyncRAT C2 (ip:port pairs), independent of specific IOC values.

```kusto
DeviceNetworkEvents
| where Timestamp > ago(1d)
| where ActionType == "ConnectionSuccess"
| where isnotempty(RemoteIP) and RemotePort !in (80, 443, 53, 123, 445, 25, 993, 995, 587, 8443)
| where InitiatingProcessFolderPath has_any (@"\appdata\local\temp\", @"\appdata\roaming\", @"\programdata\", @"\users\public\", @"\downloads\", @"\windows\temp\")
| where not(ipv4_is_private(RemoteIP))
| summarize ConnCount = count(), DistinctPorts = dcount(RemotePort), Ports = make_set(RemotePort, 10), RemoteIPs = make_set(RemoteIP, 10), FirstSeen = min(Timestamp), LastSeen = max(Timestamp)
    by DeviceName, InitiatingProcessFileName, InitiatingProcessFolderPath, InitiatingProcessSHA256, InitiatingProcessAccountName, InitiatingProcessCommandLine
| where ConnCount >= 5
| project FirstSeen, LastSeen, DeviceName, InitiatingProcessAccountName, InitiatingProcessFileName, InitiatingProcessFolderPath, InitiatingProcessCommandLine, InitiatingProcessSHA256, ConnCount, DistinctPorts, Ports, RemoteIPs
```

**Tuning notes:** Allowlist legitimate user-space apps that use odd ports (Zoom, Teams helper, game launchers, Dropbox, some VPN clients). Lower the ConnCount threshold for hunting; raise it for alerting. Pair with a check that the binary is unsigned or has low prevalence (DeviceFileEvents / global prevalence) to sharply cut noise.

**Tactic:** DefenseEvasion  
**ATT&CK:** T1055  
**Severity:** High  
**Purpose:** AsyncRAT is typically delivered via VBS/JS/PS1 loaders that launch or inject into signed .NET/Windows binaries (aspnet_compiler.exe, MSBuild.exe, RegAsm.exe, InstallUtil.exe, caspol.exe) or hollow processes like RegSvcs.exe and jsc.exe.

```kusto
DeviceProcessEvents

| where InitiatingProcessFileName in~ ("wscript.exe", "cscript.exe", "powershell.exe", "pwsh.exe", "mshta.exe", "cmd.exe", "rundll32.exe", "regsvr32.exe", "winword.exe", "excel.exe")
```

**Tuning notes:** Developer workstations and CI agents legitimately invoke MSBuild/csc.exe from cmd or PowerShell — scope out build servers and dev OUs, or require the parent script to reside in a user-writable directory. aspnet_compiler.exe and Microsoft.Workflow.Compiler.exe launched by wscript/mshta is essentially always malicious.

## 7) Defender Exclusion or AMSI/Tamper Weakening via Command Line

**Tactic:** DefenseEvasion  
**ATT&CK:** T1562.001  
**Severity:** High  
**Purpose:** Loaders (OffLoader/PavinLoader, Amadey-dropped payloads) and ClickFix scripts commonly add Defender exclusions or disable real-time protection/AMSI before dropping the final payload.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)

```

**Tuning notes:** Allowlist your EDR/AV management tooling and documented exclusion-management scripts run by SCCM/Intune/GPO. Exclusions added by a script interpreter whose parent is a browser, archive tool, or Office app should be treated as critical.

## 8) macOS AMOS Stealer via ClickFix Terminal Paste (curl/osascript Pipe to Shell)

**Tactic:** Execution  
**ATT&CK:** T1059.004  
**Severity:** High  
**Purpose:** IClickFix campaigns targeting Mac users instruct victims to paste a Terminal command that curls a payload and pipes it to bash/zsh, often combined with osascript password prompts — detects this pattern on macOS endpoints onboarded to Defender.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where FileName in~ ("bash", "sh", "zsh", "curl", "osascript", "python3")
| where ProcessCommandLine has_any ("curl", "wget") and ProcessCommandLine has_any ("| bash", "|bash", "| sh", "|sh", "| zsh", "|zsh", "-o /tmp/", "> /tmp/")
    or (FileName =~ "osascript" and ProcessCommandLine has_any ("display dialog", "with hidden answer", "password", "administrator privileges"))
| project Timestamp, DeviceName, AccountName, FileName, ProcessCommandLine, FolderPath, InitiatingProcessFileName, InitiatingProcessCommandLine, ProcessId, ReportId
```

**Tuning notes:** Developer machines commonly use 'curl | bash' for tooling installs (Homebrew, nvm, rustup) — allowlist known installer domains by inspecting the URL in the command line, and exclude engineering device groups. osascript password prompts spawned by a shell descended from Terminal shortly after browser activity are the highest-fidelity subset.

## 9) Rapid Host and Domain Reconnaissance Burst Following Remote-Session or Script Execution

**Tactic:** Discovery  
**ATT&CK:** T1082  
**Severity:** Medium  
**Purpose:** Detects the discovery burst typical after exploitation of internet-facing services (ScreenConnect, GitLab, Artifactory) or loader execution, where many recon commands are launched by a single shell/RMM/script parent within a short window.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where FileName in~ ("whoami.exe", "systeminfo.exe", "ipconfig.exe", "net.exe", "net1.exe", "nltest.exe", "arp.exe", "tasklist.exe", "quser.exe", "query.exe", "hostname.exe", "route.exe", "netstat.exe", "wmic.exe", "dsquery.exe", "klist.exe")
| where InitiatingProcessFileName in~ ("cmd.exe", "powershell.exe", "pwsh.exe", "wscript.exe", "cscript.exe", "mshta.exe", "w3wp.exe", "java.exe", "ruby.exe", "node.exe", "screenconnect.clientservice.exe", "screenconnect.windowsbackstageshell.exe", "sh", "bash")
| summarize ReconCommands = dcount(FileName), CommandList = make_set(ProcessCommandLine, 25), FirstSeen = min(Timestamp), LastSeen = max(Timestamp)
    by DeviceName, AccountName, InitiatingProcessFileName, InitiatingProcessId, InitiatingProcessCommandLine
| where ReconCommands >= 4
| project FirstSeen, LastSeen, DeviceName, AccountName, InitiatingProcessFileName, InitiatingProcessCommandLine, ReconCommands, CommandList
```

**Tuning notes:** Tune the ReconCommands threshold (4-6) per environment. Allowlist inventory/monitoring agents and logon scripts. Highest severity when the parent is a web/app service account (w3wp, java for GitLab/Artifactory) or an RMM binary, indicating post-exploitation of an internet-facing service.

## 10) Web/Application Server Process Spawning a Shell (GitLab, Artifactory, Java/Ruby Services)

**Tactic:** Execution  
**ATT&CK:** T1059  
**Severity:** Critical  
**Purpose:** Detects post-exploitation command execution stemming from vulnerable internet-facing applications such as GitLab (CVE-2026-85706 path traversal) and JFrog Artifactory (CVE-2026-42016 / CVE-2026-42018 auth bypass), where the service process spawns an interactive shell or recon/download utility.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFileName in~ ("java.exe", "java", "ruby.exe", "ruby", "puma", "unicorn", "nginx.exe", "nginx", "w3wp.exe", "httpd", "node.exe", "node", "tomcat9.exe", "catalina.sh", "gitlab-workhorse", "artifactory")
| where FileName in~ ("cmd.exe", "powershell.exe", "pwsh.exe", "bash", "sh", "dash", "zsh", "python", "python3", "perl", "curl", "curl.exe", "wget", "certutil.exe", "whoami.exe", "whoami", "nc", "ncat", "socat")
| project Timestamp, DeviceName, AccountName, InitiatingProcessFileName, InitiatingProcessFolderPath, InitiatingProcessCommandLine, FileName, FolderPath, ProcessCommandLine, SHA256, ReportId
```

**Tuning notes:** GitLab and Artifactory legitimately spawn shells for hooks, backups and CI runners — baseline the recurring parent/child command lines on these servers (e.g., gitlab-shell, git, gc jobs) and allowlist them. Alert with high priority on reverse-shell indicators (nc/socat, '/dev/tcp/', 'bash -i') or any download utility fetching from an external IP.

## 11) LOLBin Download of Payload to User-Writable Directory

**Tactic:** CommandAndControl  
**ATT&CK:** T1105  
**Severity:** Medium  
**Purpose:** Covers loader/dropper staging common to ClearFake, IClickFix and Unknown Loader (OffLoader/PavinLoader) chains: certutil, bitsadmin, curl, msiexec or PowerShell fetching remote content into AppData/Temp/ProgramData/Public.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where FileName in~ ("certutil.exe", "bitsadmin.exe", "curl.exe", "msiexec.exe", "powershell.exe", "pwsh.exe", "mshta.exe", "regsvr32.exe", "rundll32.exe", "expand.exe", "finger.exe")
| where ProcessCommandLine has_any ("http://", "https://", "ftp://", "\\\\")
| where ProcessCommandLine has_any ("-urlcache", "-decode", "/transfer", "-o ", "--output", "-OutFile", "DownloadFile", "DownloadString", "Invoke-WebRequest", "Invoke-RestMethod", "Start-BitsTransfer", "/i ")
| where ProcessCommandLine has_any (@"\appdata\", @"\temp\", @"%temp%", @"\programdata\", @"\users\public\", @"$env:temp", @"\windows\temp\", @"\downloads\")
| project Timestamp, DeviceName, AccountName, FileName, ProcessCommandLine, FolderPath, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessFolderPath, SHA256, ReportId
```

**Tuning notes:** Allowlist internal update/patching infrastructure URLs and management agents (Intune, SCCM, Chocolatey/winget from approved sources). Correlate the downloaded file name with subsequent process execution or persistence writes to prioritize. Consider excluding certutil usage by PKI administration scripts.
