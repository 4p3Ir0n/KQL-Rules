## 1) ClickFix / ClearFake: Malicious command pasted into Windows Run dialog (RunMRU)

**Tactic:** Execution  
**ATT&CK:** T1204.004  
**Severity:** High  
**Purpose:** ClearFake/ClickFix lures instruct victims to paste a command into the Win+R Run dialog. Windows records that string in the Explorer RunMRU registry key, giving a high-fidelity artifact of the social-engineering execution step.

```kusto
DeviceRegistryEvents
| where Timestamp > ago(1d)
| where RegistryKey has @"\Explorer\RunMRU"
| where RegistryValueData has_any ("powershell","pwsh","mshta","curl","certutil","bitsadmin","msiexec","rundll32","regsvr32","conhost","wscript","cscript","cmd /c","cmd.exe /c","iwr","irm","iex","invoke-expression","frombase64string","-enc","-w h","-windowstyle hidden","\\\\")
| project Timestamp, DeviceId, DeviceName, InitiatingProcessAccountName, RegistryKey, RegistryValueName, RegistryValueData, InitiatingProcessFileName, ReportId
```

**Tuning notes:** Admins/developers legitimately run cmd/powershell from Run; suppress on known IT workstations or when RegistryValueData is a bare interpreter name with no arguments. Consider requiring length(RegistryValueData) > 40 or presence of a URL/base64 blob to cut noise. The trailing \\ term catches UNC-path pastes; allowlist known file-server paths.

## 2) Script interpreter spawned directly by Explorer with download or encoded-command arguments

**Tactic:** Execution  
**ATT&CK:** T1059.001  
**Severity:** High  
**Purpose:** Detects the execution stage of ClickFix/ClearFake and similar paste-and-run lures, where explorer.exe (Run dialog or double-clicked lure file) launches an interpreter that retrieves or decodes a remote payload.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFileName =~ "explorer.exe"
| where FileName in~ ("powershell.exe","pwsh.exe","cmd.exe","mshta.exe","wscript.exe","cscript.exe","rundll32.exe","regsvr32.exe","msiexec.exe","curl.exe","certutil.exe","bitsadmin.exe","node.exe")
| where ProcessCommandLine has_any ("http://","https://","-enc","-ec ","frombase64string","iex","invoke-expression","invoke-webrequest","downloadstring","downloadfile","webclient","-w hidden","-windowstyle hidden","bypass","javascript:","\\\\")
| project Timestamp, DeviceId, DeviceName, AccountName, FileName, ProcessCommandLine, FolderPath, InitiatingProcessFileName, InitiatingProcessCommandLine, ReportId
```

**Tuning notes:** Baseline software-deployment scripts and admin shortcuts launched from Explorer. Shortcut (.lnk) launches also appear with explorer.exe as parent — pivot on InitiatingProcessCommandLine. If volume is high, restrict to non-admin accounts or require both a URL and an obfuscation keyword.

## 3) EtherHiding: script host or browser child process contacting blockchain RPC endpoints

**Tactic:** CommandAndControl  
**ATT&CK:** T1102  
**Severity:** Medium  
**Purpose:** ClearFake and related campaigns store C2/payload instructions in smart contracts and fetch them via public Web3 RPC endpoints (EtherHiding). Script interpreters or non-browser processes talking to blockchain RPC nodes are highly anomalous on endpoints.

```kusto
DeviceNetworkEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFileName in~ ("powershell.exe","pwsh.exe","mshta.exe","wscript.exe","cscript.exe","cmd.exe","curl.exe","node.exe","rundll32.exe","regsvr32.exe","msbuild.exe","conhost.exe")
| where RemoteUrl has_any ("bsc-dataseed","binance.org","bscrpc","rpc.ankr.com","cloudflare-eth.com","eth-mainnet","infura.io","alchemyapi.io","publicnode.com","llamarpc.com","drpc.org","blockpi.network")
| project Timestamp, DeviceId, DeviceName, InitiatingProcessAccountName, InitiatingProcessFileName, InitiatingProcessCommandLine, RemoteUrl, RemoteIP, RemotePort, ReportId
```

**Tuning notes:** Legitimate crypto/dev tooling (wallets, hardhat, web3 SDKs) will match — allowlist by device group or by InitiatingProcessFolderPath under developer directories. RPC provider lists rotate; maintain the domain list as a watchlist function rather than inline.

## 4) Run key persistence pointing to executable in user-writable directory (AsyncRAT pattern)

**Tactic:** Persistence  
**ATT&CK:** T1547.001  
**Severity:** High  
**Purpose:** AsyncRAT, Amadey and most commodity RATs/stealers persist by writing an autorun value referencing a copy of themselves in AppData, Temp, ProgramData or Public. Detects the persistence step independent of hash/domain IOCs.

```kusto
DeviceRegistryEvents
| where Timestamp > ago(1d)
| where ActionType in ("RegistryValueSet","RegistryKeyCreated")
| where RegistryKey has_any (@"CurrentVersion\Run", @"CurrentVersion\RunOnce", @"CurrentVersion\Policies\Explorer\Run", @"Windows\CurrentVersion\RunServices")
| where RegistryValueData has_any (@"\AppData\Roaming", @"\AppData\Local\Temp", @"\Windows\Temp", @"\ProgramData", @"\Users\Public", @"\Downloads", @"\Music", @"\Pictures")
| where RegistryValueData has_any (".exe",".bat",".cmd",".vbs",".js",".ps1",".scr",".pif",".lnk")
| project Timestamp, DeviceId, DeviceName, InitiatingProcessAccountName, InitiatingProcessFileName, InitiatingProcessCommandLine, RegistryKey, RegistryValueName, RegistryValueData, ReportId
```

**Tuning notes:** Some legitimate per-user apps (Teams, Slack, Zoom updaters, OneDrive) install into AppData\Local — allowlist by specific RegistryValueData substrings for vendor paths, not by process name. Raise severity when the writing process is a script host or itself runs from Temp.

## 5) Scheduled task created to launch binary from a user-writable path with elevated/logon trigger

**Tactic:** Persistence  
**ATT&CK:** T1053.005  
**Severity:** Medium  
**Purpose:** AsyncRAT and loaders such as Amadey commonly create schtasks entries with /rl highest or ONLOGON/MINUTE triggers pointing at a dropped payload in Temp/AppData/ProgramData.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where FileName =~ "schtasks.exe"
| where ProcessCommandLine has_any ("/create","/CREATE","-create")
| where ProcessCommandLine has_any ("appdata","\\temp\\","programdata","users\\public","downloads","%tmp%","%temp%")
| where ProcessCommandLine has_any ("/rl highest","onlogon","onstart","/sc minute","/sc hourly","/ru system")
| project Timestamp, DeviceId, DeviceName, AccountName, ProcessCommandLine, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessFolderPath, ReportId
```

**Tuning notes:** Software installers and patch tooling create tasks referencing ProgramData — allowlist by InitiatingProcessFolderPath (e.g., known deployment agents). Also consider pairing with DeviceFileEvents to confirm the target binary was written in the previous hour.

## 6) Binary in user-writable directory beaconing to non-standard high ports (AsyncRAT/quasar family)

**Tactic:** CommandAndControl  
**ATT&CK:** T1571  
**Severity:** Medium  
**Purpose:** AsyncRAT builds default to hardcoded non-web ports (6606/7707/8808 and similar) and run from AppData/Temp. Detects repeated outbound connections from untrusted paths to uncommon ports, catching the family's C2 behaviour rather than perishable IPs.

```kusto
DeviceNetworkEvents
| where Timestamp > ago(1d)
| where ActionType == "ConnectionSuccess"
| where InitiatingProcessFolderPath has_any (@"\AppData\Roaming", @"\AppData\Local\Temp", @"\Windows\Temp", @"\ProgramData", @"\Users\Public", @"\Downloads")
| where RemotePort !in (80, 443, 53, 8080, 123, 22, 25, 587)
| where not(ipv4_is_private(RemoteIP))
| summarize Connections = count(), Ports = make_set(RemotePort, 10), Peers = dcount(RemoteIP), FirstSeen = min(Timestamp), LastSeen = max(Timestamp) by DeviceId, DeviceName, InitiatingProcessFileName, InitiatingProcessFolderPath, InitiatingProcessAccountName, RemoteIP
| where Connections >= 5
| project FirstSeen, LastSeen, DeviceId, DeviceName, InitiatingProcessAccountName, InitiatingProcessFileName, InitiatingProcessFolderPath, RemoteIP, Ports, Connections, Peers
```

**Tuning notes:** Game launchers, chat clients and updaters installed per-user will surface; allowlist by InitiatingProcessFileName + folder pairs after baselining a week. Tighten by adding a beacon-regularity check (stdev of inter-arrival times) or by restricting RemotePort to the 4000-65535 range.

## 7) Non-browser process reading browser credential and cookie stores

**Tactic:** CredentialAccess  
**ATT&CK:** T1555.003  
**Severity:** High  
**Purpose:** RustyStealer and other commodity infostealers copy or read Chromium/Gecko credential databases ('Login Data', 'Local State', cookies, logins.json). Detects the collection behaviour regardless of payload hash.

```kusto
DeviceFileEvents
| where Timestamp > ago(1d)
| where FileName in~ ("Login Data","Login Data For Account","Local State","Web Data","Cookies","logins.json","key4.db","key3.db","cookies.sqlite","places.sqlite") or FolderPath has_any (@"\Network\Cookies", @"\Local Extension Settings")
| where InitiatingProcessFileName !in~ ("chrome.exe","msedge.exe","firefox.exe","brave.exe","opera.exe","opera_gx.exe","vivaldi.exe","msedgewebview2.exe","chrome_proxy.exe","MsMpEng.exe","backgroundTaskHost.exe","explorer.exe","searchindexer.exe")
| project Timestamp, DeviceId, DeviceName, ActionType, FileName, FolderPath, InitiatingProcessAccountName, InitiatingProcessFileName, InitiatingProcessFolderPath, InitiatingProcessCommandLine, InitiatingProcessSHA256, ReportId
```

**Tuning notes:** Backup agents, profile-migration tools, EDR/DLP scanners and browser sync utilities trigger this — allowlist by signed InitiatingProcessFolderPath. Highest fidelity when InitiatingProcessFolderPath is under Temp/AppData or the process is unsigned; add that filter if volume is high.

## 8) Stealer-style staging: process from Temp/AppData enumerating crypto wallet and credential directories

**Tactic:** Collection  
**ATT&CK:** T1005  
**Severity:** Medium  
**Purpose:** Infostealers dropped by loaders such as Amadey iterate wallet extensions, wallet.dat, VPN and messenger config files before exfiltration. Detects mass touching of high-value data paths by an untrusted binary.

```kusto
DeviceFileEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFolderPath has_any (@"\AppData\Local\Temp", @"\AppData\Roaming", @"\ProgramData", @"\Users\Public", @"\Downloads", @"\Windows\Temp")
| where FolderPath has_any ("wallet.dat","\\Exodus\\","\\Electrum\\","\\Ethereum\\","\\Bitcoin\\","\\Telegram Desktop\\tdata","\\Discord\\Local Storage","\\FileZilla\\","\\OpenVPN\\","\\ProtonVPN\\","\\.ssh\\","\\Steam\\config","\\Authy\\","nkbihfbeogaeaoehlefnkodbefgpgknn")
| summarize TargetsTouched = dcount(FolderPath), Samples = make_set(FolderPath, 15), Actions = make_set(ActionType, 5), FirstSeen = min(Timestamp), LastSeen = max(Timestamp) by DeviceId, DeviceName, InitiatingProcessFileName, InitiatingProcessFolderPath, InitiatingProcessSHA256, InitiatingProcessAccountName
| where TargetsTouched >= 3
| project FirstSeen, LastSeen, DeviceId, DeviceName, InitiatingProcessAccountName, InitiatingProcessFileName, InitiatingProcessFolderPath, InitiatingProcessSHA256, TargetsTouched, Samples, Actions
```

**Tuning notes:** Backup, sync and antivirus scanners running from ProgramData can match — allowlist specific signed agents. Lower TargetsTouched to 2 for hunting, raise to 5 for alerting. Extend the path list with wallet extension IDs relevant to your environment.

## 9) Unattended remote-access tool (ScreenConnect/ConnectWise) installed or launched from a browser/mail/temp context

**Tactic:** CommandAndControl  
**ATT&CK:** T1219  
**Severity:** High  
**Purpose:** Campaigns in this feed abuse ScreenConnect as a C2/remote-access implant. Detects silent RMM client installs and clients executing from user-writable paths or spawned by browsers, mail clients or archive tools.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where FileName has_any ("ScreenConnect","ConnectWiseControl","connectwise") or ProcessCommandLine has_any ("ScreenConnect.ClientSetup","ScreenConnect.WindowsClient","&e=Access&y=Guest","connectwisecontrol.com/?")
| where InitiatingProcessFileName in~ ("chrome.exe","msedge.exe","firefox.exe","outlook.exe","winrar.exe","7zfm.exe","explorer.exe","powershell.exe","pwsh.exe","cmd.exe","mshta.exe","wscript.exe","msiexec.exe","curl.exe")
    or FolderPath has_any (@"\AppData\Local\Temp", @"\AppData\Roaming", @"\Downloads", @"\Users\Public", @"\ProgramData")
| project Timestamp, DeviceId, DeviceName, AccountName, FileName, FolderPath, ProcessCommandLine, ProcessVersionInfoCompanyName, InitiatingProcessFileName, InitiatingProcessCommandLine, SHA256, ReportId
```

**Tuning notes:** If ScreenConnect/ConnectWise is a sanctioned support tool, allowlist the approved relay hostname in the command line and the installer's expected folder path, and alert only on other instance URLs. Duplicate the logic for other RMMs in scope (AnyDesk, Atera, Splashtop, TacticalRMM).

## 10) Defender exclusion or tamper commands issued from an untrusted parent process

**Tactic:** DefenseEvasion  
**ATT&CK:** T1562.001  
**Severity:** High  
**Purpose:** Loaders (Amadey, AsyncRAT droppers, ClickFix chains) frequently add AV exclusions or disable real-time monitoring before dropping the final payload. Detects tamper attempts driven by script hosts or binaries in user-writable paths.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where ProcessCommandLine has_any ("Add-MpPreference","Set-MpPreference","ExclusionPath","ExclusionExtension","ExclusionProcess","DisableRealtimeMonitoring","DisableBehaviorMonitoring","DisableIOAVProtection","MpCmdRun.exe -RemoveDefinitions","sc stop windefend","sc delete windefend","sc config windefend")
| where InitiatingProcessFileName in~ ("explorer.exe","mshta.exe","wscript.exe","cscript.exe","winword.exe","excel.exe","outlook.exe","rundll32.exe","regsvr32.exe","msiexec.exe","curl.exe","node.exe","cmd.exe","powershell.exe")
    or InitiatingProcessFolderPath has_any (@"\AppData\Local\Temp", @"\AppData\Roaming", @"\ProgramData", @"\Downloads", @"\Users\Public")
| project Timestamp, DeviceId, DeviceName, AccountName, FileName, ProcessCommandLine, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessFolderPath, ReportId
```

**Tuning notes:** Exclude your endpoint management tooling (SCCM/Intune remediation scripts, packaging accounts) by InitiatingProcessFolderPath or AccountName. Any exclusion added by a process under Temp should be treated as confirmed-malicious and escalated immediately.

## 11) Acronis Backup plugin service spawning shell or privilege-modifying commands (CVE-2026-87886 context)

**Tactic:** PrivilegeEscalation  
**ATT&CK:** T1574  
**Severity:** Medium  
**Purpose:** CVE-2026-87886 is an incorrect-default-permissions privilege escalation in the Acronis Backup plugin for cPanel/WHM and Plesk. On Defender for Endpoint Linux hosts, abuse would manifest as the Acronis plugin component or a web/panel user spawning shells or changing ownership/permissions of privileged files.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFolderPath has_any ("acronis", "/usr/local/cpanel", "/opt/psa", "/usr/local/psa")
    or InitiatingProcessFileName has_any ("acronis", "cpanel", "sw-engine")
| where FileName in~ ("sh","bash","dash","zsh","chmod","chown","chattr","useradd","usermod","sudo","su","crontab","systemctl","curl","wget","python3","perl")
| project Timestamp, DeviceId, DeviceName, AccountName, FileName, ProcessCommandLine, FolderPath, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessAccountName, ReportId
```

**Tuning notes:** Backup and panel products legitimately invoke shells and systemctl during scheduled jobs — baseline recurring command lines and allowlist them, then alert on deviations (new binaries, chmod 4755/u+s, chown root, added users, outbound curl/wget). Only applicable to Linux servers onboarded to Defender for Endpoint.
