## 1) ClickFix: Explorer Run Dialog Spawning Script Interpreter with Download/Exec Pattern

**Tactic:** Execution  
**ATT&CK:** T1204.004  
**Severity:** High  
**Purpose:** Detects the core ClickFix / ClearFake social-engineering chain where a victim is tricked into pasting an attacker-supplied command into the Windows Run dialog or terminal, causing explorer.exe to spawn powershell.exe, mshta.exe, cmd.exe or conhost with download-and-execute content.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFileName =~ "explorer.exe"
| where FileName in~ ("powershell.exe","pwsh.exe","mshta.exe","cmd.exe","wscript.exe","cscript.exe","curl.exe","msiexec.exe","rundll32.exe","certutil.exe")
| where ProcessCommandLine has_any ("iex","Invoke-Expression","Invoke-WebRequest","IWR ","DownloadString","DownloadFile","FromBase64String","-enc","-EncodedCommand","-w hidden","-windowstyle hidden","http://","https://","\\\\","mshta","bitsadmin","start-process","Net.WebClient","curl ","certutil -urlcache")
| project Timestamp, DeviceName, AccountUpn, AccountName, FileName, ProcessCommandLine, InitiatingProcessFileName, InitiatingProcessCommandLine, ProcessId, SHA256, ReportId
| order by Timestamp desc
```

**Tuning notes:** explorer.exe -> cmd.exe is somewhat common for power users; tighten by requiring network-indicative keywords (already applied) or exclude known admin accounts/jump hosts. Add allowlist for internal software-deployment UNC paths. Consider pairing with the RunMRU registry detection for higher confidence.

## 2) ClickFix: Suspicious Command Written to Explorer RunMRU History

**Tactic:** Execution  
**ATT&CK:** T1059.001  
**Severity:** High  
**Purpose:** ClickFix lures instruct the user to press Win+R and paste a payload command; Windows records the typed string in HKCU\...\Explorer\RunMRU. Detecting script/download keywords in RunMRU values provides durable forensic evidence of the lure even if the payload is cleaned up.

```kusto
DeviceRegistryEvents
| where Timestamp > ago(1d)
| where RegistryKey has "\\Explorer\\RunMRU"
| where isnotempty(RegistryValueData)
| where RegistryValueData has_any ("powershell","pwsh","mshta","msiexec","curl","certutil","bitsadmin","rundll32","wscript","cscript","conhost","http://","https://","FromBase64String","-enc","iex","Invoke-","cmd /c","cmd.exe /c","\u2713","verification","captcha","I am not a robot")
| project Timestamp, DeviceName, AccountName, RegistryKey, RegistryValueName, RegistryValueData, InitiatingProcessFileName, InitiatingProcessAccountName, ReportId
| order by Timestamp desc
```

**Tuning notes:** Admins legitimately type cmd/powershell into Run; suppress bare values like "powershell\\1" by requiring URL/encoding keywords, or alert only on RunMRU values longer than ~80 characters. Baseline per-user to spot first-time occurrences.

## 3) ClickFix/ClearFake: msiexec Installing a Remotely Hosted MSI Package

**Tactic:** Execution  
**ATT&CK:** T1218.007  
**Severity:** High  
**Purpose:** ClickFix and ClearFake campaigns (tagged msiexec, OnDevicePayload) frequently deliver the second stage via msiexec installing an MSI directly from a remote URL, bypassing browser download controls.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where FileName =~ "msiexec.exe"
| where ProcessCommandLine has_any ("http://","https://","\\\\")
| where ProcessCommandLine has_any ("/i","-i","/package","/quiet","/qn","/qb")
| extend Suspicious = ProcessCommandLine has_any ("/quiet","/qn","/norestart")
| project Timestamp, DeviceName, AccountName, FileName, ProcessCommandLine, InitiatingProcessFileName, InitiatingProcessCommandLine, Suspicious, SHA256, ReportId
| order by Timestamp desc
```

**Tuning notes:** Allowlist internal software-distribution URLs/UNC shares and SCCM/Intune content hosts by RemoteUrl substring. Parent process of browser, explorer.exe, mshta.exe or powershell.exe materially raises confidence.

## 4) BITS Transfer to Domain with Uncommon TLD (Sigma translation)

**Tactic:** CommandAndControl  
**ATT&CK:** T1197  
**Severity:** Medium  
**Purpose:** Faithful endpoint translation of the Sigma rule 'Bitsadmin to Uncommon TLD': BITS-initiated network connections (bitsadmin.exe, BITS service in svchost, PowerShell Start-BitsTransfer) to hosts outside the common/legitimate TLD set used for software updates.

```kusto
DeviceNetworkEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFileName in~ ("bitsadmin.exe","svchost.exe","powershell.exe","pwsh.exe")
| where InitiatingProcessFileName =~ "bitsadmin.exe"
    or (InitiatingProcessFileName =~ "svchost.exe" and InitiatingProcessCommandLine has "BITS")
    or InitiatingProcessCommandLine has_any ("Start-BitsTransfer","bitsadmin")
| extend Host = tolower(iff(isnotempty(RemoteUrl), tostring(parse_url(RemoteUrl).Host), RemoteUrl))
| where isnotempty(Host) and not(Host matches regex @"^\d{1,3}(\.\d{1,3}){3}$")
| where not (Host endswith ".com" or Host endswith ".microsoft" or Host endswith ".net" or Host endswith ".org" or Host endswith ".scdn.co" or Host endswith ".sfx.ms")
| project Timestamp, DeviceName, AccountName, Host, RemoteUrl, RemoteIP, RemotePort, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessAccountName, ReportId
| order by Timestamp desc
```

**Tuning notes:** Extend the legitimate-TLD filter with your organisation's ccTLDs (e.g. .co.uk, .de) and vendor CDNs. Raw-IP destinations are excluded here to limit noise but can be re-enabled as a separate, higher-severity variant. If proxy logs are available, correlate on the 'Microsoft BITS/' user agent.

## 5) ScreenConnect/ConnectWise Client Executed from Temporary or User-Writable Path

**Tactic:** CommandAndControl  
**ATT&CK:** T1219  
**Severity:** Medium  
**Purpose:** Per ISC diary on ScreenConnect abuse, attackers deploy the legitimate ConnectWise/ScreenConnect client as a RAT. Execution from Temp/Downloads/AppData or installation by a script interpreter indicates unsanctioned remote-access tooling.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where FileName has_any ("ScreenConnect","ConnectWiseControl") or ProcessVersionInfoProductName has_any ("ScreenConnect","ConnectWise Control")
    or ProcessCommandLine has_any ("ScreenConnect.ClientSetup","e=Access&y=Guest","screenconnect.com/Bin","&p=443&s=")
| extend LowerPath = tolower(FolderPath)
| where LowerPath has_any ("\\appdata\\local\\temp\\","\\downloads\\","\\users\\public\\","\\programdata\\","\\appdata\\roaming\\","\\windows\\temp\\")
    or InitiatingProcessFileName in~ ("powershell.exe","pwsh.exe","cmd.exe","mshta.exe","wscript.exe","cscript.exe","msiexec.exe","rundll32.exe","explorer.exe","outlook.exe","winword.exe","excel.exe")
| project Timestamp, DeviceName, AccountName, FileName, FolderPath, ProcessCommandLine, ProcessVersionInfoCompanyName, InitiatingProcessFileName, InitiatingProcessCommandLine, SHA256, ReportId
| order by Timestamp desc
```

**Tuning notes:** If ScreenConnect is an approved tool, allowlist your instance's relay hostname/customer ID found in the client command line and the sanctioned install path under Program Files; alert only on unknown instance identifiers. Pair with DeviceNetworkEvents for connections to *.screenconnect.com relays not matching your tenant.

## 6) Mirai/Gafgyt Linux Dropper: Remote Fetch Piped to Shell or chmod +x in World-Writable Path

**Tactic:** Execution  
**ATT&CK:** T1059.004  
**Severity:** High  
**Purpose:** Mirai and Gafgyt variants infect Linux/IoT hosts by downloading an ELF via wget/curl/tftp/busybox into /tmp or /dev/shm, making it executable, and running it. Detects the download->chmod->execute pattern and fetch-pipe-to-shell one-liners on Defender for Endpoint Linux agents.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where FileName in~ ("sh","bash","dash","busybox","wget","curl","tftp","ftpget","chmod")
| where ProcessCommandLine has_any ("wget","curl","tftp","ftpget","busybox")
    and ProcessCommandLine has_any ("chmod +x","chmod 777","chmod 755","| sh","|sh","| bash","|bash","-O -","-qO-","/tmp/","/dev/shm/","/var/tmp/","/var/run/")
| project Timestamp, DeviceName, AccountName, FileName, FolderPath, ProcessCommandLine, InitiatingProcessFileName, InitiatingProcessCommandLine, SHA256, ReportId
| order by Timestamp desc
```

**Tuning notes:** Legitimate provisioning/config-management (Ansible, cloud-init, container entrypoints, package post-install scripts) matches this pattern; allowlist by InitiatingProcessFileName (ansible, salt-minion, cloud-init) and by known build/CI hosts. Raise severity when the fetch target is a raw IP:port or a dynamic-DNS domain (e.g. *.duckdns.org).

## 7) Remote Monitoring Tool Installed as Service or Scheduled Task Shortly After Script Execution

**Tactic:** Persistence  
**ATT&CK:** T1543.003  
**Severity:** Medium  
**Purpose:** Follows the ScreenConnect abuse pattern: after initial script-based access, attackers persist the RMM agent as a Windows service or scheduled task. Detects service/task creation referencing remote-access tooling binaries outside sanctioned install paths.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where FileName in~ ("sc.exe","schtasks.exe","powershell.exe","pwsh.exe","reg.exe")
| where ProcessCommandLine has_any ("ScreenConnect","ConnectWise","AnyDesk","atera","splashtop","TacticalRMM","MeshAgent","RustDesk","SimpleHelp","Supremo","NetSupport")
| where ProcessCommandLine has_any ("create","config","/create","New-Service","Register-ScheduledTask","binPath","/tr ")
| project Timestamp, DeviceName, AccountName, FileName, ProcessCommandLine, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessParentFileName, SHA256, ReportId
| order by Timestamp desc
```

**Tuning notes:** Allowlist the single RMM product your IT team is licensed to use, plus its deployment service account and install path; any other vendor name in this list on a managed endpoint should be treated as unauthorized. Correlate with DeviceNetworkEvents to the vendor relay domains for confirmation.
