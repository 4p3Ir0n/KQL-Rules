## 1) ClickFix / FakeCaptcha: Malicious Command Pasted Into Windows Run Dialog (RunMRU)

**Tactic:** Execution  
**ATT&CK:** T1204.004  
**Severity:** High  
**Purpose:** ClearFake, 'Unknown Loader' and 'Unknown Stealer' ClickFix/FakeCaptcha lures instruct victims to paste an attacker-supplied command into the Windows Run dialog. Every pasted command is persisted in the Explorer RunMRU registry key, making this a high-fidelity, IOC-independent detection of the initial execution step.

```kusto
DeviceRegistryEvents
| where Timestamp > ago(1d)
| where ActionType in ("RegistryValueSet", "RegistryKeyCreated")
| where RegistryKey has @"\Explorer\RunMRU"
| where RegistryValueData has_any ("powershell", "pwsh", "cmd.exe", "cmd /c", "mshta", "curl ", "certutil", "bitsadmin", "msiexec", "wscript", "cscript", "rundll32", "conhost", "forfiles", "\\\\")
    or RegistryValueData has_any ("-enc", "-ec ", "FromBase64String", "iwr ", "irm ", "Invoke-WebRequest", "Invoke-Expression", "IEX", "DownloadString", "hidden", "-w h", "http://", "https://", "✅", "verification", "captcha")
| project Timestamp, DeviceId, DeviceName, AccountName, RegistryKey, RegistryValueName, RegistryValueData, InitiatingProcessFileName, InitiatingProcessAccountName, ReportId
```

**Tuning notes:** RunMRU writes are user-driven and rare in most enterprises. Allowlist admin/helpdesk workstations and known internal UNC paths or scripted tooling. Tighten by requiring both an interpreter keyword and a URL/encoding keyword if volume is high. Correlate with a DeviceProcessEvents hit for the same user within 60 seconds to confirm execution.

## 2) ClickFix / FileFix: Explorer.exe Spawning Script Interpreter With Download-and-Execute Command Line

**Tactic:** Execution  
**ATT&CK:** T1059.001  
**Severity:** High  
**Purpose:** Detects the execution stage of ClickFix (Run dialog) and FileFix (File Explorer address bar) social-engineering chains used by ClearFake, Unknown Loader and Unknown Stealer campaigns, where explorer.exe directly launches a hidden/encoded PowerShell, cmd, mshta or curl command that fetches a remote payload.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFileName =~ "explorer.exe"
| where FileName in~ ("powershell.exe", "pwsh.exe", "cmd.exe", "mshta.exe", "wscript.exe", "cscript.exe", "curl.exe", "certutil.exe", "bitsadmin.exe", "msiexec.exe", "rundll32.exe", "regsvr32.exe")
| where ProcessCommandLine has_any ("http://", "https://", "-enc", "-ec ", "-e ", "FromBase64String", "DownloadString", "DownloadFile", "Invoke-WebRequest", "Invoke-RestMethod", "iwr ", "irm ", "IEX", "Invoke-Expression", "Start-BitsTransfer", "\\\\", "-w hidden", "-windowstyle hidden", "-nop")
| project Timestamp, DeviceId, DeviceName, AccountName, FileName, FolderPath, ProcessCommandLine, InitiatingProcessFileName, InitiatingProcessCommandLine, SHA256, ReportId
```

**Tuning notes:** Explorer launching an interpreter with a URL is almost always user-pasted content. Exclude signed internal admin scripts launched from Explorer and software deployment tooling. If PowerShell profile/console launches from Explorer are common in your estate, require the URL or encoding keywords only (drop bare interpreter launches).

## 3) mshta.exe or Script Host Executing Remote Content

**Tactic:** Execution  
**ATT&CK:** T1218.005  
**Severity:** Medium  
**Purpose:** ClickFix/FakeCaptcha and loader chains frequently stage second-stage payloads via mshta.exe or WSH pulling remote HTA/JS content. Detects LOLBin execution referencing remote URLs or script protocols regardless of the specific infrastructure used.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where FileName in~ ("mshta.exe", "wscript.exe", "cscript.exe", "rundll32.exe", "regsvr32.exe")
| where ProcessCommandLine has_any ("http://", "https://", "javascript:", "vbscript:", "about:", "\\\\")
| where not(InitiatingProcessFileName in~ ("ccmexec.exe", "msiexec.exe") and ProcessCommandLine has "\\\\")
| project Timestamp, DeviceId, DeviceName, AccountName, FileName, ProcessCommandLine, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessFolderPath, SHA256, ReportId
```

**Tuning notes:** Allowlist legacy line-of-business HTA/VBS apps hosted on known internal web servers or UNC shares by URL substring or initiating process. regsvr32 /i with scriptlet URLs should be treated as higher severity.

## 4) PowerShell Dynamic Module Invocation Via ExportedCommands Array Index (Process Creation)

**Tactic:** Execution  
**ATT&CK:** T1027.010  
**Severity:** Medium  
**Purpose:** Translation of Sigma rule 0c3ebe9f-df09-4e00-be0f-73d4ca8d62f6. Detects PowerShell command lines that enumerate Microsoft.PowerShell.Utility exported commands and invoke cmdlets indirectly by array index to evade string-based detection of Invoke-Expression / Invoke-RestMethod.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where FileName in~ ("powershell.exe", "pwsh.exe") or ProcessVersionInfoOriginalFileName in~ ("powershell.exe", "pwsh.dll")
| where ProcessCommandLine has_any ("Get-Module ", "gmo ")
| where ProcessCommandLine contains "ListAvailable"
    and ProcessCommandLine contains "Microsoft.PowerShell.Utility"
    and ProcessCommandLine contains "ExportedCommands"
    and ProcessCommandLine contains "Values"
| where ProcessCommandLine matches regex @"\[[^\]]*\]"
| project Timestamp, DeviceId, DeviceName, AccountName, FileName, ProcessCommandLine, InitiatingProcessFileName, InitiatingProcessCommandLine, ProcessVersionInfoOriginalFileName, SHA256, ReportId
```

**Tuning notes:** Expected false-positive rate is near zero; legitimate automation rarely resolves cmdlets by array index. If an internal obfuscation/red-team tool triggers it, allowlist by signing certificate of the initiating process or by device group rather than removing the pattern.

## 5) PowerShell Script Block: ExportedCommands Array-Index Cmdlet Invocation

**Tactic:** Execution  
**ATT&CK:** T1059.001  
**Severity:** Medium  
**Purpose:** Translation of Sigma rule 4ff4ad3e-9fb5-4a70-9962-d6ea58090318 (ps_script logsource). Detects obfuscated script blocks that enumerate Microsoft.PowerShell.Utility exported commands and invoke them by array index, bypassing detections keyed on literal cmdlet names.

```kusto
DeviceEvents
| where Timestamp > ago(1d)
| where ActionType in ("PowerShellCommand", "ScriptContent")
| extend ScriptBlockText = coalesce(tostring(parse_json(AdditionalFields).Command), tostring(parse_json(AdditionalFields).ScriptBlockText), tostring(parse_json(AdditionalFields).ScriptContent))
| where isnotempty(ScriptBlockText)
| where ScriptBlockText has_any ("Get-Module ", "gmo ")
| where ScriptBlockText contains "ListAvailable"
    and ScriptBlockText contains "Microsoft.PowerShell.Utility"
    and ScriptBlockText contains "ExportedCommands"
    and ScriptBlockText contains "Values"
| where ScriptBlockText matches regex @"\[[^\]]*\]"
| project Timestamp, DeviceId, DeviceName, AccountName, ActionType, ScriptBlockText, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessAccountName, ReportId
```

**Tuning notes:** Requires PowerShell script block logging forwarded to Defender (DeviceEvents ActionType PowerShellCommand / ScriptContent); verify the AdditionalFields key name in your tenant and adjust the coalesce. Long script blocks may be truncated - consider also alerting when only three of the four keywords match plus the index regex.

## 6) Linux Download-Chmod-Execute Chain (Mirai/Gafgyt Style Dropper)

**Tactic:** Execution  
**ATT&CK:** T1059.004  
**Severity:** High  
**Purpose:** Mirai, Gafgyt, HailBot and related IoT/Linux botnets propagate via shell one-liners that fetch a binary with wget/curl/tftp into a world-writable directory, chmod it executable and run it. Detects the behavior rather than the rotating C2 infrastructure.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where ProcessCommandLine has_any ("wget", "curl", "tftp", "ftpget", "busybox")
| where ProcessCommandLine has_any ("chmod 777", "chmod +x", "chmod 755", "chmod u+x")
| where ProcessCommandLine has_any ("/tmp/", "/var/tmp/", "/dev/shm/", "/var/run/", "/mnt/", "./")
| project Timestamp, DeviceId, DeviceName, AccountName, FileName, FolderPath, ProcessCommandLine, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessParentFileName, SHA256, ReportId
```

**Tuning notes:** Scope to Linux devices. Allowlist CI/CD build agents, container image build hosts and configuration-management runners (Ansible, Chef, Salt) by device group or initiating process. Raise severity when the parent is a web server, database or IoT management daemon, which indicates remote exploitation.

## 7) Remote Script Piped Directly To Shell (curl|bash) on Linux/macOS

**Tactic:** Execution  
**ATT&CK:** T1059.004  
**Severity:** High  
**Purpose:** OffLoader, MacStealer and Web3 supply-chain intrusions commonly execute 'curl https://... | sh' style one-liners for staging. Detects fetch-and-pipe-to-interpreter execution independent of the hosting domain.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where ProcessCommandLine matches regex @"(?i)(curl|wget|fetch)\s[^|;]{0,300}\|\s*(sudo\s+)?(ba|z|da|k|s|fi)?sh\b"
    or ProcessCommandLine matches regex @"(?i)(curl|wget)\s[^|;]{0,300}\|\s*(python3?|perl|ruby|node|osascript)\b"
| project Timestamp, DeviceId, DeviceName, AccountName, FileName, FolderPath, ProcessCommandLine, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessParentFileName, ReportId
```

**Tuning notes:** Common in developer and DevOps workflows (Homebrew, rustup, nvm installers) - allowlist by device group for engineering endpoints or by known installer domains present in the command line. Prioritize events where the initiating process is a browser, terminal spawned by a browser, mail client, or a web/application server.

## 8) Non-Browser Process Accessing Browser Credential And Wallet Stores

**Tactic:** CredentialAccess  
**ATT&CK:** T1555.003  
**Severity:** High  
**Purpose:** Infostealers tracked under 'Unknown Stealer' (RustyStealer, RemusStealer, YapStealer, ValetiStealer, MacStealer) harvest browser login databases, cookies and crypto wallet files. Detects access/copy of these artifacts by processes that are not the owning browser.

```kusto
DeviceFileEvents
| where Timestamp > ago(1d)
| where ActionType in ("FileCreated", "FileModified", "FileRenamed", "FileCopied")
    or FileName has_any ("Login Data", "Cookies", "Web Data", "key4.db", "logins.json", "wallet.dat")
| where FolderPath has_any (@"\User Data\", @"\Mozilla\Firefox\Profiles", "/Library/Application Support/Google/Chrome", "/Library/Application Support/Firefox", "Exodus", "Electrum", "Ethereum", "MetaMask")
    or FileName in~ ("Login Data", "key4.db", "logins.json", "wallet.dat", "Cookies", "Web Data")
| where not(InitiatingProcessFileName in~ ("chrome.exe", "msedge.exe", "firefox.exe", "brave.exe", "opera.exe", "Google Chrome", "firefox", "Safari", "msedgewebview2.exe"))
| project Timestamp, DeviceId, DeviceName, AccountName, ActionType, FileName, FolderPath, InitiatingProcessFileName, InitiatingProcessFolderPath, InitiatingProcessCommandLine, InitiatingProcessSHA256, ReportId
```

**Tuning notes:** Allowlist backup agents, endpoint DLP/forensic tools, browser-sync utilities and IT migration tooling by initiating process path and signer. Highest-value hits are unsigned binaries running from %TEMP%, %APPDATA%, /tmp or ~/Downloads, or scripting hosts (powershell, python, osascript).

## 9) Package Manager Install Script Spawning Shell or Network Downloader

**Tactic:** Execution  
**ATT&CK:** T1195.002  
**Severity:** High  
**Purpose:** Per Unit 42's Web3/cloud supply-chain research, malicious npm/pip/gem packages execute postinstall hooks that spawn shells and fetch payloads (often from Web3/IPFS gateways). Detects package-manager processes spawning interpreters or downloaders during dependency installation.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFileName in~ ("node.exe", "node", "npm.exe", "npm", "npx", "yarn", "pnpm", "python.exe", "python3", "pip.exe", "pip3", "gem", "ruby")
| where FileName in~ ("powershell.exe", "pwsh.exe", "cmd.exe", "bash", "sh", "zsh", "curl.exe", "curl", "wget", "certutil.exe", "bitsadmin.exe", "osascript", "chmod", "base64")
| where ProcessCommandLine has_any ("http://", "https://", "ipfs", "eth", "base64", "FromBase64String", "-enc", "DownloadString", "Invoke-Expression", "IEX", "/tmp/", "%TEMP%", "chmod +x", "curl ", "wget ")
| project Timestamp, DeviceId, DeviceName, AccountName, FileName, ProcessCommandLine, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessFolderPath, SHA256, ReportId
```

**Tuning notes:** Noisy on developer workstations and build agents; baseline per-repo build commands and allowlist known internal registries/mirrors by URL substring. Focus first on installs that reach non-registry hosts, IPFS/Web3 gateways, or raw.githubusercontent.com, and on hosts that are not designated build infrastructure.

## 10) Cloud Credential And Token Files Read By Scripting Or Package-Manager Processes

**Tactic:** CredentialAccess  
**ATT&CK:** T1552.001  
**Severity:** High  
**Purpose:** Web3/open-source supply-chain intrusions pivot into cloud environments by harvesting local cloud credential material (~/.aws/credentials, kube config, .npmrc tokens, GCP ADC). Detects access to those files by interpreters and package managers rather than legitimate cloud CLIs.

```kusto
DeviceFileEvents
| where Timestamp > ago(1d)
| where FolderPath has_any (".aws", ".azure", ".kube", ".docker", ".config/gcloud", ".npmrc", ".pypirc", ".git-credentials", ".ssh")
    or FileName in~ ("credentials", "config.json", ".npmrc", ".pypirc", "application_default_credentials.json", "id_rsa", ".git-credentials")
| where InitiatingProcessFileName in~ ("node.exe", "node", "npm", "npx", "yarn", "pnpm", "python.exe", "python3", "pip", "ruby", "gem", "powershell.exe", "pwsh.exe", "bash", "sh", "zsh", "curl.exe", "curl", "osascript")
| project Timestamp, DeviceId, DeviceName, AccountName, ActionType, FileName, FolderPath, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessFolderPath, InitiatingProcessAccountName, ReportId
```

**Tuning notes:** Exclude legitimate cloud CLIs (aws.exe, az.exe, gcloud, kubectl, terraform) and CI runners that legitimately template credentials. Correlate within a short window with the package-manager-spawn detection or with outbound connections from the same process to flag exfiltration.

## 11) Atlassian Confluence/Jira Java Process Spawning Shell or Reconnaissance Commands

**Tactic:** InitialAccess  
**ATT&CK:** T1190  
**Severity:** High  
**Purpose:** Following active scanning for CVE-2026-21589 (Atlassian arbitrary file access), detects post-exploitation on Atlassian application servers where the Tomcat/Java service account spawns shells, downloaders or recon commands - the behavioral signal of successful exploitation or chained RCE.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFileName in~ ("java", "java.exe", "tomcat9.exe", "tomcat10.exe", "catalina.sh")
| where InitiatingProcessCommandLine has_any ("confluence", "jira", "bitbucket", "atlassian", "bamboo", "catalina")
| where FileName in~ ("sh", "bash", "dash", "zsh", "cmd.exe", "powershell.exe", "pwsh.exe", "curl", "curl.exe", "wget", "whoami", "whoami.exe", "id", "uname", "cat", "net.exe", "net1.exe", "nltest.exe", "certutil.exe", "python3", "perl", "base64", "chmod")
| project Timestamp, DeviceId, DeviceName, AccountName, FileName, FolderPath, ProcessCommandLine, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessAccountName, SHA256, ReportId
```

**Tuning notes:** Atlassian apps legitimately spawn helper processes (e.g. backup scripts, LibreOffice/convert for attachments, git/ssh on Bitbucket) - baseline these per server and allowlist by exact command line. Pay particular attention to 'cat' or shell reads of confluence.cfg.xml, dbconfig.xml, server.xml and local-home properties files, which align with the CVE-2026-21589 arbitrary file read primitive.

## 12) Browser-Spawned Interpreter With Encoded or Clipboard-Delivered Payload

**Tactic:** DefenseEvasion  
**ATT&CK:** T1140  
**Severity:** Medium  
**Purpose:** ClearFake/EtherHiding and FakeCaptcha pages lead users to execute commands sourced from a compromised web page. Detects a browser process directly spawning a script interpreter that decodes or downloads content - a strong signal of drive-by social-engineering execution without relying on rotating domains.

```kusto
DeviceProcessEvents

| project Timestamp, DeviceId, DeviceName, AccountName, FileName, FolderPath, ProcessCommandLine, InitiatingProcessFileName, InitiatingProcessCommandLine, SHA256, ReportId
```

**Tuning notes:** Browsers legitimately launch helper processes for protocol handlers and enterprise SSO; allowlist specific signed helper binaries and known internal URL handlers. Treat osascript spawned by a browser on macOS (MacStealer password-prompt phishing) as high severity.
