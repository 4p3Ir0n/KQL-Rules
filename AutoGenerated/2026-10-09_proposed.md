## 1) PowerShell Script Block: Dynamic Cmdlet Invocation via ExportedCommands Array Index

**Tactic:** Execution  
**ATT&CK:** T1059.001  
**Severity:** Medium  
**Purpose:** Translates Sigma rule 4ff4ad3e (ps_script) to Advanced Hunting. Detects obfuscated PowerShell script blocks that enumerate Microsoft.PowerShell.Utility exported commands and invoke cmdlets indirectly by array index to evade string-based detection of Invoke-Expression / Invoke-RestMethod.

```kusto
DeviceEvents
| where Timestamp > ago(1d)
| where ActionType in~ ("PowerShellCommand", "ScriptBlockLogging")
| extend ScriptBlockText = tostring(parse_json(tostring(AdditionalFields)).Command)
| where isnotempty(ScriptBlockText)
| where ScriptBlockText has_any ("Get-Module ", "gmo ")
| where ScriptBlockText contains "ListAvailable"
    and ScriptBlockText contains "Microsoft.PowerShell.Utility"
    and ScriptBlockText contains "ExportedCommands"
    and ScriptBlockText contains "Values"
| where ScriptBlockText matches regex @"\[[^\]]{0,16}\]"
| project Timestamp, DeviceId, DeviceName, AccountName, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessParentFileName, ScriptBlockText, ReportId
```

**Tuning notes:** Requires Script Block Logging to be forwarded into DeviceEvents (ActionType PowerShellCommand); field name inside AdditionalFields can vary by sensor version - validate with a sample event. Legitimate module-introspection scripts (packaging, CI, PowerShell SDK tooling) may enumerate ExportedCommands; allowlist by InitiatingProcessFolderPath of known build agents rather than by text. Tighten the index regex to @"\[\s*\d+\s*\]" if noise is high.

## 2) PowerShell Command Line: Indirect Cmdlet Invocation via ExportedCommands Index

**Tactic:** Execution  
**ATT&CK:** T1027.010  
**Severity:** Medium  
**Purpose:** Translates Sigma rule 0c3ebe9f (process_creation) to DeviceProcessEvents. Detects powershell.exe/pwsh.exe launched with an obfuscated command line that resolves cmdlets through the Microsoft.PowerShell.Utility ExportedCommands dictionary by array index.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where FileName in~ ("powershell.exe", "pwsh.exe")
    or ProcessVersionInfoOriginalFileName in~ ("powershell.exe", "pwsh.dll")
| where ProcessCommandLine has_any ("Get-Module ", "gmo ")
| where ProcessCommandLine contains "ListAvailable"
    and ProcessCommandLine contains "Microsoft.PowerShell.Utility"
    and ProcessCommandLine contains "ExportedCommands"
    and ProcessCommandLine contains "Values"
| where ProcessCommandLine matches regex @"\[[^\]]{0,16}\]"
| project Timestamp, DeviceId, DeviceName, AccountName, AccountDomain, FileName, ProcessCommandLine, ProcessId, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessParentFileName, ReportId
```

**Tuning notes:** Very low expected volume - treat any hit as high-fidelity. If the loader base64-encodes the payload the strings will not appear on the command line; pair with the ps_script variant for coverage. Consider widening to any command line combining 'ExportedCommands' with an index accessor regardless of module name.

## 3) ClickFix: Malicious Command Pasted into Windows Run Dialog (RunMRU)

**Tactic:** Execution  
**ATT&CK:** T1204.004  
**Severity:** High  
**Purpose:** ClearFake, Unknown Loader and Unknown Stealer campaigns tagged ClickFix/FileFix instruct victims to paste an attacker-supplied command into the Win+R Run dialog. The pasted text is persisted to the Explorer RunMRU registry key, giving a durable artifact independent of changing domains.

```kusto
DeviceRegistryEvents
| where Timestamp > ago(1d)
| where ActionType in ("RegistryValueSet", "RegistryKeyCreated")
| where RegistryKey has @"\Explorer\RunMRU"
| where RegistryValueData has_any ("powershell", "pwsh", "mshta", "curl", "certutil", "bitsadmin", "msiexec", "rundll32", "wscript", "cscript", "conhost", "cmd /c", "cmd.exe /c", "iex", "invoke-expression", "invoke-webrequest", "frombase64string", "-enc", "-w h", "-windowstyle hidden", "http://", "https://", "\\\\")
| project Timestamp, DeviceId, DeviceName, InitiatingProcessAccountName, RegistryKey, RegistryValueName, RegistryValueData, InitiatingProcessFileName, InitiatingProcessCommandLine, ReportId
```

**Tuning notes:** Admins legitimately type cmd, powershell or UNC paths into Run; baseline per-user and consider excluding bare 'cmd', 'powershell' with no arguments. The padded-whitespace trick used by ClickFix (long spaces before a trailing comment) can be surfaced by adding a check for RegistryValueData length > 200. Correlate within 5 minutes with a child process of explorer.exe for confirmation.

## 4) ClickFix/FileFix: explorer.exe Spawning Scripting Host with Download or Encoded Payload

**Tactic:** Execution  
**ATT&CK:** T1059.003  
**Severity:** High  
**Purpose:** Detects the execution stage of ClickFix/FileFix social-engineering lures (ClearFake, Unknown Loader, Unknown Stealer) where the victim pastes a command into the Run dialog or the File Explorer address bar, causing explorer.exe to directly spawn a scripting interpreter that downloads and runs a payload.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFileName =~ "explorer.exe"
| where FileName in~ ("powershell.exe", "pwsh.exe", "cmd.exe", "mshta.exe", "wscript.exe", "cscript.exe", "curl.exe", "certutil.exe", "bitsadmin.exe", "msiexec.exe", "rundll32.exe", "regsvr32.exe", "conhost.exe")
| where ProcessCommandLine has_any ("http://", "https://", "iex", "invoke-expression", "invoke-webrequest", "invoke-restmethod", "downloadstring", "downloadfile", "frombase64string", "-enc", "-encodedcommand", "-nop", "-w hidden", "-windowstyle hidden", "start-bitstransfer", "urlcache", "/transfer", "net.webclient", "[char]", "-join")
| project Timestamp, DeviceId, DeviceName, AccountName, FileName, ProcessCommandLine, FolderPath, ProcessId, InitiatingProcessFileName, InitiatingProcessId, ReportId
```

**Tuning notes:** Help-desk scripts and software deployment run from Explorer occasionally; allowlist by signed script paths or specific internal URLs/hostnames in ProcessCommandLine. Add 'ProcessCommandLine contains "#"' or long-whitespace checks to isolate the pasted-comment padding pattern. Consider raising severity when the command line also references clipboard or a non-corporate TLD.

## 5) EtherHiding: Browser or Script Host Contacting Public Blockchain RPC Endpoints

**Tactic:** CommandAndControl  
**ATT&CK:** T1102  
**Severity:** Medium  
**Purpose:** ClearFake uses EtherHiding - storing the next-stage payload/C2 configuration in smart contracts read via public Web3 RPC endpoints. Detects endpoint connections to blockchain RPC infrastructure from browsers or scripting hosts on non-developer machines.

```kusto
DeviceNetworkEvents
| where Timestamp > ago(1d)
| where RemoteUrl has_any ("bsc-dataseed", "binance.org", "bscrpc", "rpc.ankr.com", "cloudflare-eth.com", "infura.io", "alchemyapi.io", "g.alchemy.com", "publicnode.com", "llamarpc.com", "blockpi.network", "nodereal.io", "drpc.org")
| where InitiatingProcessFileName in~ ("chrome.exe", "msedge.exe", "firefox.exe", "brave.exe", "opera.exe", "powershell.exe", "pwsh.exe", "mshta.exe", "wscript.exe", "cscript.exe", "curl.exe", "node.exe", "rundll32.exe")
| summarize Connections = count(), Urls = make_set(RemoteUrl, 20), FirstSeen = min(Timestamp), LastSeen = max(Timestamp)
    by DeviceId, DeviceName, InitiatingProcessAccountName, InitiatingProcessFileName, InitiatingProcessCommandLine
| project FirstSeen, LastSeen, DeviceId, DeviceName, InitiatingProcessAccountName, InitiatingProcessFileName, InitiatingProcessCommandLine, Connections, Urls
```

**Tuning notes:** Exclude developer/crypto-business workstations and known Web3 wallet extensions via a device or user allowlist. Hits from powershell.exe, mshta.exe or wscript.exe are far more suspicious than from a browser - split severity accordingly. RPC provider list should be reviewed monthly; it is infrastructure-class, not single-IOC, so it ages slowly.

## 6) macOS ClickFix: Terminal/Script Host Executing Piped Remote Shell Payload

**Tactic:** Execution  
**ATT&CK:** T1059.004  
**Severity:** High  
**Purpose:** ClearFake and MacStealer ClickFix variants targeting macOS instruct victims to paste a 'curl ... | bash' one-liner into Terminal, or use osascript to run a downloaded shell script. Detects the curl/wget-to-shell pipe and osascript download chains on macOS endpoints.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where ProcessCommandLine matches regex @"(?i)(curl|wget)\s[^|;]{0,300}\|\s*(bash|sh|zsh|python3?|osascript)"
    or (FileName =~ "osascript" and ProcessCommandLine has_any ("curl", "wget", "do shell script", "base64"))
    or (ProcessCommandLine has_any ("curl", "wget") and ProcessCommandLine has_any ("/tmp/", "/var/tmp/", "/Users/Shared/") and ProcessCommandLine has_any ("chmod +x", "chmod 777", "xattr -c", "xattr -d com.apple.quarantine"))
| project Timestamp, DeviceId, DeviceName, AccountName, FileName, FolderPath, ProcessCommandLine, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessParentFileName, ReportId
```

**Tuning notes:** Homebrew, Rosetta installers and many legitimate dev tools use curl|bash - allowlist by trusted domains inside ProcessCommandLine (brew.sh, internal mirrors) or restrict to non-engineering device groups. The xattr quarantine-removal clause is the highest-fidelity component and can be promoted to its own rule. Parent process Terminal.app/iTerm strongly indicates human paste (ClickFix) versus automation.

## 7) Java Application Server Spawning OS Shell (Struts Dynamic Method Invocation RCE)

**Tactic:** InitialAccess  
**ATT&CK:** T1190  
**Severity:** Critical  
**Purpose:** Detects post-exploitation of Apache Struts command-injection flaws such as CVE-2016-3081 (method:prefix / Dynamic Method Invocation), where the Tomcat/JBoss/WebLogic JVM hosting the Struts app spawns a command interpreter or reconnaissance binary.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFileName in~ ("java.exe", "javaw.exe", "java", "tomcat.exe", "tomcat9.exe", "tomcat10.exe", "jsvc", "w3wp.exe")
| where FileName in~ ("cmd.exe", "powershell.exe", "pwsh.exe", "bash", "sh", "dash", "zsh", "whoami.exe", "whoami", "net.exe", "net1.exe", "ipconfig.exe", "ifconfig", "curl.exe", "curl", "wget", "certutil.exe", "bitsadmin.exe", "nc", "ncat", "python", "python3", "perl")
| project Timestamp, DeviceId, DeviceName, AccountName, FileName, FolderPath, ProcessCommandLine, ProcessId, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessFolderPath, InitiatingProcessId, ReportId
```

**Tuning notes:** Some Java applications legitimately shell out (build servers, monitoring agents, report generation) - allowlist specific parent command lines or device groups rather than the whole java.exe parent. Recon commands (whoami, ipconfig, net) immediately after a web request are the strongest signal; chain with DeviceNetworkEvents inbound connections to the app port for context. Also applies to other Java-stack RCEs beyond Struts.

## 8) Web Application Service Writing Script/Webshell to Web-Accessible Directory

**Tactic:** Persistence  
**ATT&CK:** T1505.003  
**Severity:** High  
**Purpose:** Covers path-traversal upload-to-RCE flaws such as ONLYOFFICE Docs CVE-2021-3199 and Strapi admin-panel chains (CVE-2023-22894 + CVE-2023-22621): the web service process writes an executable script into its own served content or working directory, the hallmark of webshell/backdoor drop.

```kusto
DeviceFileEvents
| where Timestamp > ago(1d)
| where ActionType in ("FileCreated", "FileModified", "FileRenamed")
| where InitiatingProcessFileName in~ ("node.exe", "node", "w3wp.exe", "httpd.exe", "httpd", "nginx.exe", "nginx", "java.exe", "java", "php-cgi.exe", "php-fpm", "python", "python3", "DocumentServer.exe", "converter", "docservice")
| where FileName endswith ".js" or FileName endswith ".jsp" or FileName endswith ".jspx" or FileName endswith ".php" or FileName endswith ".aspx" or FileName endswith ".asp" or FileName endswith ".ashx" or FileName endswith ".sh" or FileName endswith ".ps1" or FileName endswith ".exe" or FileName endswith ".dll"
| where FolderPath has_any ("wwwroot", "htdocs", "webapps", "public_html", "/var/www/", "sdkjs", "web-apps", "/app/", "document-server", "onlyoffice", "strapi", "/build/", "/uploads/", "/public/")
    or FolderPath has_any ("..\\", "../")
| project Timestamp, DeviceId, DeviceName, InitiatingProcessAccountName, InitiatingProcessFileName, InitiatingProcessCommandLine, ActionType, FileName, FolderPath, SHA256, ReportId
```

**Tuning notes:** Node/Java app deployments and hot-reload builds legitimately write .js into app folders - exclude CI/CD service accounts, deployment windows and known build paths (node_modules, .next, dist) or restrict the rule to production servers with immutable content. Highest fidelity when the writing process is the HTTP worker rather than a packaging tool. Pair with the Java/Node shell-spawn rule to confirm exploitation.

## 9) Repeated ISC BIND named Service Crash or Restart (CVE-2015-5477 TKEY DoS)

**Tactic:** Impact  
**ATT&CK:** T1499.004  
**Severity:** Low  
**Purpose:** CVE-2015-5477 lets a remote attacker terminate the BIND named daemon with a crafted TKEY query. Detects repeated abnormal termination or restart of the named/ISC BIND process on DNS servers, which is the only endpoint-visible effect of exploitation.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where FileName in~ ("named", "named.exe") or InitiatingProcessFileName in~ ("named", "named.exe")
| extend Context = iff(FileName in~ ("named", "named.exe"), "named_start", "named_child")
| summarize Starts = countif(Context == "named_start"), ChildProcs = make_set_if(ProcessCommandLine, Context == "named_child", 10), FirstSeen = min(Timestamp), LastSeen = max(Timestamp)
    by DeviceId, DeviceName, bin(Timestamp, 1h)
| where Starts >= 3
| project Timestamp, DeviceId, DeviceName, Starts, ChildProcs, FirstSeen, LastSeen
```

**Tuning notes:** Only deploy to DNS server device groups; scheduled config reloads or zone-transfer maintenance can cause legitimate restarts - raise the Starts threshold to match the server's normal restart rate. This is a weak proxy signal: correlate with BIND syslog ('REQUIRE(!dns_name_used(name))' assertion failure) and with inbound UDP/53 spikes in DeviceNetworkEvents for confirmation. Patch status verification is the primary control.
