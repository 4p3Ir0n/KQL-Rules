## 1) ClickFix: Malicious command staged via Windows Run dialog (RunMRU)

**Tactic:** Execution  
**ATT&CK:** T1204.004  
**Severity:** High  
**Purpose:** ClearFake/IClickFix and similar 'ClickFix' lures instruct victims to paste an attacker-supplied command into the Windows Run dialog. Every executed Run entry is recorded in the RunMRU registry key, making this a durable, IOC-independent detection of the social-engineering step itself.

```kusto
DeviceRegistryEvents | where Timestamp > ago(1d) | where RegistryKey has @"CurrentVersion\Explorer\RunMRU" | where RegistryValueData has_any ("powershell","pwsh","cmd.exe","cmd /c","mshta","msiexec","rundll32","regsvr32","curl","bitsadmin","certutil","wscript","cscript","conhost","FromBase64String","iex","Invoke-WebRequest","IWR","-enc","-nop","hidden","http://","https://","\\\\") | project Timestamp, DeviceId, DeviceName, InitiatingProcessAccountUpn, InitiatingProcessAccountName, RegistryKey, RegistryValueName, RegistryValueData, InitiatingProcessFileName, ReportId
```

**Tuning notes:** Admins and helpdesk staff legitimately type cmd.exe/powershell into Run; consider excluding bare values (RegistryValueData in ('cmd.exe\\1','powershell\\1')) and focus on entries longer than ~40 chars or containing URLs/base64. Allowlist known IT automation accounts and jump hosts. Pair with a join to DeviceProcessEvents within 5 minutes on the same device for higher fidelity.

## 2) Script interpreter spawned directly by explorer.exe with download/encoded payload

**Tactic:** Execution  
**ATT&CK:** T1059.001  
**Severity:** High  
**Purpose:** ClickFix / FakeCaptcha chains (ClearFake, IClickFix, Unknown Loader) end with explorer.exe (Run dialog, Explorer address bar, or paste-to-terminal) launching PowerShell, mshta, curl or msiexec that pulls a second stage. Detects the post-paste execution regardless of the rotating delivery domains.

```kusto
DeviceProcessEvents | where Timestamp > ago(1d) | where InitiatingProcessFileName =~ "explorer.exe" | where FileName in~ ("powershell.exe","pwsh.exe","cmd.exe","mshta.exe","wscript.exe","cscript.exe","curl.exe","msiexec.exe","rundll32.exe","regsvr32.exe","bitsadmin.exe","certutil.exe","conhost.exe") | where ProcessCommandLine has_any ("http://","https://","FromBase64String","-enc","-EncodedCommand","-nop","-w hidden","-windowstyle hidden","IEX","Invoke-Expression","Invoke-WebRequest","Net.WebClient","DownloadString","DownloadFile","irm ","iwr ","--headless","\\\\") | project Timestamp, DeviceId, DeviceName, AccountName, FileName, ProcessCommandLine, FolderPath, InitiatingProcessFileName, InitiatingProcessCommandLine, SHA256, ReportId
```

**Tuning notes:** Software deployment tools and user-launched shortcuts can trigger this; allowlist specific signed installer paths and internal UNC shares. If noisy, require ProcessCommandLine length > 120 characters or restrict to non-admin user accounts. Consider excluding msiexec invocations pointing at internal repositories.

## 3) FileFix: command disguised with comment padding or decoy document path

**Tactic:** Execution  
**ATT&CK:** T1204.004  
**Severity:** High  
**Purpose:** The FileFix variant used by recent loader campaigns tricks users into pasting a PowerShell command into the File Explorer address bar, padded with a '#' comment and a fake document path so the victim only sees a benign-looking file name. Detects the characteristic comment-padded command line.

```kusto
DeviceProcessEvents | where Timestamp > ago(1d) | where FileName in~ ("powershell.exe","pwsh.exe","cmd.exe","mshta.exe","curl.exe") | where InitiatingProcessFileName in~ ("explorer.exe","winword.exe","excel.exe","outlook.exe","chrome.exe","msedge.exe","firefox.exe") | where ProcessCommandLine contains "#" | where ProcessCommandLine has_any (".pdf",".docx",".doc",".xlsx",".zip","\\\\","C:\\") | where ProcessCommandLine has_any ("http","IEX","Invoke-","FromBase64String","-enc","curl","mshta","WebClient","-nop","hidden") | project Timestamp, DeviceId, DeviceName, AccountName, FileName, ProcessCommandLine, InitiatingProcessFileName, InitiatingProcessCommandLine, SHA256, ReportId
```

**Tuning notes:** '#' in command lines is rare for interactive users but can appear in developer tooling; allowlist developer workstations or specific parent paths. Tighten by requiring the '#' to be followed by a drive letter or UNC path via matches regex @'#\s*(\\\\|[A-Za-z]:\\)'.

## 4) LOLBin download from code/paste hosting or TOR gateway domains

**Tactic:** CommandAndControl  
**ATT&CK:** T1105  
**Severity:** Medium  
**Purpose:** Unknown Loader / OffLoader campaigns stage payloads on GitHub raw, paste sites and TOR gateways and retrieve them with built-in Windows downloaders. Detects the staging-retrieval behavior independent of the specific rotating URLs.

```kusto
DeviceProcessEvents | where Timestamp > ago(1d) | where FileName in~ ("powershell.exe","pwsh.exe","curl.exe","certutil.exe","bitsadmin.exe","mshta.exe","msiexec.exe","rundll32.exe","wscript.exe","cscript.exe") | where ProcessCommandLine has_any ("raw.githubusercontent.com","gist.githubusercontent.com","github.com","pastebin.com","paste.ee","rentry.co","transfer.sh","bitbucket.org","gitlab.io",".onion","onion.ws","onion.moe","onion.ly","tor2web","discordapp.com/attachments","cdn.discordapp.com","files.catbox.moe","bashupload") | where ProcessCommandLine has_any ("DownloadString","DownloadFile","Invoke-WebRequest","iwr","irm","-urlcache","-o ","--output","/transfer","IEX","Invoke-Expression","Start-BitsTransfer") | project Timestamp, DeviceId, DeviceName, AccountName, FileName, ProcessCommandLine, FolderPath, InitiatingProcessFileName, InitiatingProcessCommandLine, SHA256, ReportId
```

**Tuning notes:** Developer and DevOps hosts routinely curl GitHub; scope out engineering device groups or allowlist specific repository URLs. Raise severity when the parent is explorer.exe, a browser, or an Office application. Consider splitting GitHub (high volume) from paste/TOR domains (low volume) into separate analytics.

## 5) Unix shell one-liner piping remote content to an interpreter (curl|bash)

**Tactic:** Execution  
**ATT&CK:** T1059.004  
**Severity:** High  
**Purpose:** macOS ClickFix variants of ClearFake/IClickFix and Linux loaders instruct the victim (or an exploit) to run a curl/wget one-liner piped straight into bash/sh/python, executing the payload without touching disk.

```kusto
DeviceProcessEvents | where Timestamp > ago(1d) | where FileName in~ ("bash","sh","zsh","dash","python","python3","perl","osascript","curl","wget") | where ProcessCommandLine matches regex @"(?i)(curl|wget)\s[^|;]{0,300}\|\s*(sudo\s+)?(ba|z|da)?sh|python3?\s*-" | where ProcessCommandLine has_any ("http://","https://") | project Timestamp, DeviceId, DeviceName, AccountName, FileName, ProcessCommandLine, FolderPath, InitiatingProcessFileName, InitiatingProcessCommandLine, ProcessId, ReportId
```

**Tuning notes:** Package managers, Homebrew installs and CI agents use this pattern legitimately — allowlist known install endpoints (brew.sh, get.docker.com, internal artifact hosts) and build-server device groups. On macOS, parent processes Terminal.app/iTerm2 driven by a browser-initiated paste are the highest-fidelity cases.

## 6) Mirai/Gafgyt-style multi-architecture binary download, chmod and execution

**Tactic:** Execution  
**ATT&CK:** T1059.004  
**Severity:** High  
**Purpose:** Mirai, Gafgyt and Ngioweb loaders fetch architecture-specific ELF droppers (bins.sh, mirai.x86, .mpsl, .arm7), chmod them executable from a world-writable directory and run them. Detects the loader behavior rather than the short-lived hosting IPs.

```kusto
DeviceProcessEvents | where Timestamp > ago(1d) | where FileName in~ ("sh","bash","busybox","wget","curl","tftp","ftpget","dash") | where ProcessCommandLine matches regex @"(?i)(wget|curl|tftp|ftpget|busybox)\b[^;&|]{0,250}(\.(sh|mips|mpsl|arm[0-7]?|x86|x86_64|i[3-6]86|ppc|spc|sh4|arc|m68k|sparc)\b|/bins?/)" or (ProcessCommandLine has_any ("chmod 777","chmod +x","chmod 755") and ProcessCommandLine has_any ("/tmp/","/dev/shm/","/var/run/","/var/tmp/","/mnt/")) | project Timestamp, DeviceId, DeviceName, AccountName, FileName, ProcessCommandLine, FolderPath, InitiatingProcessFileName, InitiatingProcessCommandLine, ProcessId, ReportId
```

**Tuning notes:** Expect hits from legitimate build/deploy scripts and container image bootstrapping; allowlist CI/CD hosts and known artifact URLs. Highest fidelity when the parent is a network-facing service (dropbear, httpd, telnetd) or when the download host is a bare IP:port — add 'ProcessCommandLine matches regex @\"\\d{1,3}(\\.\\d{1,3}){3}:\\d+\"' to tighten.

## 7) Java/Tomcat web application spawning a command interpreter (Struts-style RCE)

**Tactic:** InitialAccess  
**ATT&CK:** T1190  
**Severity:** Critical  
**Purpose:** Exploitation of Apache Struts command injection (e.g., CVE-2016-3081 method:prefix / Dynamic Method Invocation) results in the Java application server process spawning an OS shell or recon utility. This process-lineage detection covers Struts and most other Java web-app RCE chains.

```kusto
DeviceProcessEvents | where Timestamp > ago(1d) | where InitiatingProcessFileName in~ ("java.exe","javaw.exe","java","jsvc","tomcat.exe","tomcat9.exe","catalina.sh","w3wp.exe") | where FileName in~ ("cmd.exe","powershell.exe","pwsh.exe","sh","bash","dash","whoami.exe","whoami","net.exe","net1.exe","ipconfig.exe","ifconfig","hostname","id","uname","curl.exe","curl","wget","certutil.exe","bitsadmin.exe","python.exe","python3","nc","ncat") | project Timestamp, DeviceId, DeviceName, AccountName, FileName, ProcessCommandLine, FolderPath, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessId, SHA256, ReportId
```

**Tuning notes:** Some Java applications legitimately shell out (report generation, backup scripts, monitoring). Baseline per-server and allowlist recurring parent command lines or specific child command lines. Internet-facing Struts/Tomcat servers should be treated as Critical with no suppression.

## 8) Node.js application server spawning a shell or recon command

**Tactic:** InitialAccess  
**ATT&CK:** T1190  
**Severity:** High  
**Purpose:** Strapi (CVE-2023-22894 chained with CVE-2023-22621) and ONLYOFFICE Docs (CVE-2021-3199) are Node-based services whose exploitation results in remote code execution; the first observable endpoint artifact is the node process spawning an OS command interpreter or downloader.

```kusto
DeviceProcessEvents | where Timestamp > ago(1d) | where InitiatingProcessFileName in~ ("node.exe","node","nodejs","npm","pm2","DocService.exe","converter.exe") | where FileName in~ ("cmd.exe","powershell.exe","pwsh.exe","sh","bash","dash","whoami.exe","whoami","id","uname","net.exe","curl.exe","curl","wget","certutil.exe","bitsadmin.exe","nc","ncat","python","python3","perl") | where not(ProcessCommandLine has_any ("node-gyp","npm install","yarn ","next build")) | project Timestamp, DeviceId, DeviceName, AccountName, FileName, ProcessCommandLine, FolderPath, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessId, SHA256, ReportId
```

**Tuning notes:** Build servers and local developer machines generate heavy node->shell activity; restrict this rule to production application server device groups. ONLYOFFICE DocService legitimately invokes converter helpers — allowlist those specific child image paths rather than the whole parent.

## 9) Web/document server process writing script or executable content into served directories

**Tactic:** Persistence  
**ATT&CK:** T1505.003  
**Severity:** High  
**Purpose:** Path-traversal upload flaws such as ONLYOFFICE Docs CVE-2021-3199 are weaponized by writing a script outside the intended upload directory to achieve code execution/webshell persistence. Detects server-process writes of executable content into web-served or application directories.

```kusto
DeviceFileEvents | where Timestamp > ago(1d) | where InitiatingProcessFileName in~ ("node.exe","node","nodejs","nginx.exe","nginx","httpd","apache2","w3wp.exe","java.exe","java","DocService.exe") | where ActionType in ("FileCreated","FileModified","FileRenamed") | where FileName endswith ".js" or FileName endswith ".jsp" or FileName endswith ".jspx" or FileName endswith ".php" or FileName endswith ".aspx" or FileName endswith ".asp" or FileName endswith ".ps1" or FileName endswith ".sh" or FileName endswith ".exe" or FileName endswith ".dll" or FileName endswith ".bat" | where FolderPath has_any ("\\www\\","/www/","wwwroot","htdocs","webapps","public_html","/app/","\\App\\","onlyoffice","strapi","/upload","\\upload") | project Timestamp, DeviceId, DeviceName, ActionType, FileName, FolderPath, SHA256, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessAccountName, ReportId
```

**Tuning notes:** Application deployments, auto-updates and cache generation will write .js files — allowlist deployment service accounts, CI agents and known cache/build paths (node_modules, .next, dist). Alert with higher confidence when the written file is .jsp/.php/.aspx/.exe or when the same server process spawns a shell shortly after.

## 10) Defender exclusion or AMSI/security tooling tampering immediately after user-pasted command

**Tactic:** DefenseEvasion  
**ATT&CK:** T1562.001  
**Severity:** High  
**Purpose:** ClickFix/FileFix loader chains commonly follow the pasted command with an attempt to add a Defender exclusion, disable real-time monitoring, or bypass AMSI before dropping the stealer stage. Detects the tampering step in the chain.

```kusto
DeviceProcessEvents | where Timestamp > ago(1d) | where FileName in~ ("powershell.exe","pwsh.exe","cmd.exe","wscript.exe","cscript.exe","mshta.exe") | where ProcessCommandLine has_any ("Add-MpPreference","Set-MpPreference","ExclusionPath","ExclusionExtension","ExclusionProcess","DisableRealtimeMonitoring","DisableBehaviorMonitoring","DisableIOAVProtection","DisableScriptScanning","amsiInitFailed","AmsiScanBuffer","System.Management.Automation.AmsiUtils","MpCmdRun.exe -RemoveDefinitions") | project Timestamp, DeviceId, DeviceName, AccountName, FileName, ProcessCommandLine, FolderPath, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessParentFileName, SHA256, ReportId
```

**Tuning notes:** Enterprise management tooling (SCCM/Intune scripts, EDR onboarding, backup vendors) legitimately sets exclusions — allowlist by InitiatingProcessFileName (e.g., ccmexec.exe, ansible) and by service account. Any hit where the ancestry includes explorer.exe or a browser should be treated as a true-positive candidate.
