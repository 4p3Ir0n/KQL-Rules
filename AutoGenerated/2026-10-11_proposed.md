## 1) ClickFix lure: attacker command pasted into Windows Run dialog (RunMRU)

**Tactic:** Execution  
**ATT&CK:** T1059.001  
**Severity:** High  
**Purpose:** ClearFake/IClickFix campaigns instruct victims to paste a crafted command into the Win+R Run dialog. Every pasted command is persisted under the Explorer RunMRU registry key, making this one of the highest-fidelity artifacts of a successful ClickFix social-engineering execution.

```kusto
DeviceRegistryEvents
| where Timestamp > ago(1d)
| where RegistryKey has @"\Explorer\RunMRU"
| where isnotempty(RegistryValueData)
| where RegistryValueData has_any ("powershell","pwsh","mshta","curl","certutil","bitsadmin","msiexec","rundll32","wscript","cscript","conhost","forfiles","cmd /c","cmd.exe /c","-enc","-e ","FromBase64String","iex","Invoke-Expression","Invoke-WebRequest","http://","https://","\\\\")
| extend PastedCommand = tostring(RegistryValueData)
| project Timestamp, DeviceId, DeviceName, InitiatingProcessAccountName, InitiatingProcessFileName, RegistryKey, RegistryValueName, PastedCommand, ReportId
```

**Tuning notes:** RunMRU legitimately contains cmd.exe, mstsc, \\fileserver paths typed by admins; allowlist by RegistryValueData prefix and by known admin accounts/jump hosts. Very long (>200 char) or base64-looking values should be escalated automatically. Combine with the explorer.exe-parented interpreter rule for confirmation.

## 2) Script interpreter spawned directly by explorer.exe with download or obfuscation flags (ClickFix)

**Tactic:** Execution  
**ATT&CK:** T1204.004  
**Severity:** High  
**Purpose:** Detects the execution stage of ClearFake/ClickFix 'fix-it' pages: the Run dialog or a pasted shortcut causes explorer.exe to directly spawn powershell/mshta/curl/msiexec with hidden-window, encoded, or remote-download arguments.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFileName =~ "explorer.exe"
| where FileName in~ ("powershell.exe","pwsh.exe","mshta.exe","cmd.exe","curl.exe","msiexec.exe","wscript.exe","cscript.exe","rundll32.exe","regsvr32.exe","bitsadmin.exe","certutil.exe")
| where ProcessCommandLine has_any ("-w h","-windowstyle h","hidden","-nop","-noprofile","-enc","-ec ","FromBase64String","IEX","Invoke-Expression","Invoke-WebRequest","iwr ","DownloadString","DownloadFile","Start-BitsTransfer","http://","https://","Get-Clipboard","urlmon",".hta","/i http")
| project Timestamp, DeviceId, DeviceName, AccountName, FileName, ProcessCommandLine, FolderPath, InitiatingProcessFileName, InitiatingProcessCommandLine, SHA256, ReportId
```

**Tuning notes:** Interactive admins launching powershell from Explorer with -nop are common; scope out IT/helpdesk accounts or require two or more of the suspicious tokens. Internal software-deployment HTA/MSI launched from file shares may need a FolderPath allowlist.

## 3) macOS/Linux ClickFix: curl or wget piped directly into a shell or interpreter

**Tactic:** Execution  
**ATT&CK:** T1059.004  
**Severity:** High  
**Purpose:** IClickFix and ClearFake macOS variants instruct users to paste a one-liner into Terminal that curls a payload and pipes it straight to bash/sh/osascript/python, bypassing Gatekeeper and leaving no file artifact before execution.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where FileName in~ ("bash","sh","zsh","dash","curl","wget","osascript","python","python3")
| where ProcessCommandLine has_any ("curl","wget")
| where ProcessCommandLine matches regex @"(?i)(curl|wget)\s[^|;]{3,300}\|\s*(sudo\s+)?(bash|sh|zsh|dash|osascript|python3?|perl|ruby|nohup)"
| extend SuspiciousParent = InitiatingProcessFileName in~ ("Terminal","iTerm2","osascript","Safari","Google Chrome","firefox","Microsoft Edge")
| project Timestamp, DeviceId, DeviceName, AccountName, FileName, ProcessCommandLine, FolderPath, InitiatingProcessFileName, InitiatingProcessCommandLine, SuspiciousParent, ReportId
```

**Tuning notes:** Developer workstations run legitimate 'curl ... | bash' installers (Homebrew, rustup, nvm, Docker). Allowlist the specific known-good installer hostnames in the command line, or restrict to SuspiciousParent == true for a higher-fidelity alert. Keep a separate low-noise hunt for engineering subnets.

## 4) Fake browser/software update installer dropped and executed from a browser download

**Tactic:** InitialAccess  
**ATT&CK:** T1189  
**Severity:** Medium  
**Purpose:** ClearFake (EtherHiding) injects fake browser/Chrome/Flash update overlays into compromised sites; the victim downloads and runs an installer named after the update. Detects execution of a browser-written installer whose name mimics an update package.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFileName in~ ("chrome.exe","msedge.exe","firefox.exe","brave.exe","opera.exe","iexplore.exe","Safari","Google Chrome")
| where FileName matches regex @"(?i)^(chrome|google|firefox|mozilla|edge|safari|flash|adobe|java|teams|zoom|update|updater|install|setup|driver)[^\\/]*\.(exe|msi|msix|scr|hta|js|vbs|pkg|dmg|zip)$"
   or ProcessCommandLine matches regex @"(?i)(chrome|firefox|edge|flash|adobe|java)[^\s]*update[^\s]*\.(exe|msi|hta|js)"
| where FolderPath has_any ("\\Downloads\\","\\Temp\\","\\AppData\\Local\\Temp","/Downloads/","/private/var/folders/","/tmp/")
| project Timestamp, DeviceId, DeviceName, AccountName, FileName, FolderPath, ProcessCommandLine, SHA256, InitiatingProcessFileName, InitiatingProcessCommandLine, ReportId
```

**Tuning notes:** Legitimate vendor installers are also downloaded via browsers; filter on signer (use DeviceFileCertificateInfo join) and allowlist the organisation's approved software distribution paths. Unsigned or recently-created binaries should be prioritised.

## 5) Linux dropper behaviour: payload staged in world-writable directory, made executable and run

**Tactic:** Execution  
**ATT&CK:** T1059.004  
**Severity:** High  
**Purpose:** Covers the 'Unknown Loader'/OffLoader and generic ELF dropper TTP chain: download to /tmp, /dev/shm or /var/tmp, chmod +x, then execute, often from a shell spawned by curl/wget or a TOR-fronted retrieval script.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where ProcessCommandLine matches regex @"(?i)\bchmod\s+(-[a-z]+\s+)?(\+?x|[0-7]{3,4})\s+\S*(/tmp/|/dev/shm/|/var/tmp/|/run/|/home/[^/]+/\.)"
   or (FolderPath matches regex @"^/(tmp|dev/shm|var/tmp|run)/" and InitiatingProcessFileName in~ ("sh","bash","dash","ash","busybox","curl","wget","python","python3","perl","crond","cron"))
| extend StagingDir = extract(@"^(/(?:tmp|dev/shm|var/tmp|run)/)", 1, FolderPath)
| project Timestamp, DeviceId, DeviceName, AccountName, FileName, FolderPath, StagingDir, ProcessCommandLine, InitiatingProcessFileName, InitiatingProcessCommandLine, SHA256, ReportId
```

**Tuning notes:** CI/CD runners, package managers and container build steps legitimately chmod +x in /tmp. Allowlist build-agent hostnames and known service accounts (jenkins, gitlab-runner), and exclude paths under /tmp/pip-*, /tmp/go-build*, /tmp/systemd-private-*. Consider raising severity when the executed file has no SHA256 reputation.

## 6) Mirai/Gafgyt multi-architecture ELF loader script

**Tactic:** Execution  
**ATT&CK:** T1059.004  
**Severity:** High  
**Purpose:** Mirai and Gafgyt loaders brute-force architectures by sequentially fetching mips, arm, x86, sh4, ppc and spc binaries with wget/tftp/busybox. Detects a single command line or short burst referencing several CPU architecture payload names.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where ProcessCommandLine has_any ("wget","curl","tftp","busybox","ftpget")
| extend ArchTokens = extract_all(@"(?i)[\./_-](mipsel|mipsl|mpsl|mips|arm[4-7]?|armv[4-7]l?|x86_64|x86|i[3-6]86|sh4|ppc|powerpc|spc|sparc|m68k|arc)\b", ProcessCommandLine)
| extend DistinctArchs = array_length(set_union(ArchTokens, dynamic([])))
| where DistinctArchs >= 3 or ProcessCommandLine has_any ("busybox wget","busybox tftp","tftp -g -r","/bin/busybox ")
| where ProcessCommandLine has_any ("chmod","./","http://","tftp","cd /tmp","cd /dev/shm","rm -rf")
| project Timestamp, DeviceId, DeviceName, AccountName, FileName, FolderPath, ProcessCommandLine, DistinctArchs, InitiatingProcessFileName, InitiatingProcessCommandLine, ReportId
```

**Tuning notes:** Cross-compilation / embedded firmware build hosts will match; allowlist those devices. Honeypot or IoT-emulation systems (cowrie) will generate volume — exclude by DeviceName. Lower DistinctArchs to 2 for high-value servers that should never cross-fetch binaries.

## 7) Web application server spawns a command shell or recon utility (Struts/ONLYOFFICE style RCE)

**Tactic:** InitialAccess  
**ATT&CK:** T1190  
**Severity:** Critical  
**Purpose:** Exploitation of server-side RCE such as Apache Struts Dynamic Method Invocation command injection (CVE-2016-3081) or ONLYOFFICE Docs path traversal results in the web/app server process spawning an OS shell or recon binary — a reliable post-exploitation signal independent of the specific CVE.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFileName in~ ("java","java.exe","javaw.exe","tomcat.exe","tomcat9.exe","catalina.sh","jboss","httpd","apache2","nginx","nginx.exe","w3wp.exe","node","node.exe","php-fpm","php-cgi.exe","DocService","converter")
| where FileName in~ ("cmd.exe","powershell.exe","pwsh.exe","sh","bash","dash","zsh","whoami","whoami.exe","id","uname","net.exe","net1.exe","ipconfig.exe","ifconfig","hostname","curl","curl.exe","wget","certutil.exe","bitsadmin.exe","python","python3","perl","nc","ncat","netcat","socat","chmod","crontab")
| project Timestamp, DeviceId, DeviceName, AccountName, FileName, FolderPath, ProcessCommandLine, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessFolderPath, SHA256, ReportId
```

**Tuning notes:** Some app servers legitimately shell out (deployment hooks, ImageMagick/LibreOffice converters in ONLYOFFICE, health-check scripts). Baseline per server role for 7 days and allowlist the exact parent-child-commandline triplets; never allowlist whoami/net/curl from a web process.

## 8) Web server or document service writes script/executable into web-accessible directory (webshell drop)

**Tactic:** Persistence  
**ATT&CK:** T1505.003  
**Severity:** High  
**Purpose:** Path traversal file-upload flaws such as ONLYOFFICE Docs CVE-2021-3199 are weaponised by writing a script outside the intended upload folder into a web root. Detects server-process-authored script or binary files inside served directories.

```kusto
DeviceFileEvents
| where Timestamp > ago(1d)
| where ActionType in ("FileCreated","FileModified","FileRenamed")
| where InitiatingProcessFileName in~ ("java","java.exe","javaw.exe","tomcat.exe","httpd","apache2","nginx","nginx.exe","w3wp.exe","node","node.exe","php-fpm","php-cgi.exe","DocService","converter","onlyoffice-documentserver")
| where FileName endswith ".php" or FileName endswith ".phtml" or FileName endswith ".jsp" or FileName endswith ".jspx" or FileName endswith ".asp" or FileName endswith ".aspx" or FileName endswith ".ashx" or FileName endswith ".sh" or FileName endswith ".py" or FileName endswith ".pl" or FileName endswith ".exe" or FileName endswith ".elf" or FileName endswith ".war"
| where FolderPath has_any ("/var/www","/usr/share/nginx","/srv/www","/htdocs","webapps","wwwroot","/documentserver","/var/lib/onlyoffice","/App_Data","\\inetpub\\")
| project Timestamp, DeviceId, DeviceName, ActionType, FileName, FolderPath, SHA256, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessAccountName, ReportId
```

**Tuning notes:** Exclude legitimate deployment pipelines (war/jar expansion by Tomcat into webapps, CMS auto-update writing .php). Pair with the web-server-spawns-shell rule: a file write followed by execution from the same path within minutes is near-certain compromise. Add additional web roots specific to your estate.

## 9) DNS service (named) crash-restart loop — possible BIND TKEY DoS exploitation

**Tactic:** Impact  
**ATT&CK:** T1499.004  
**Severity:** Low  
**Purpose:** CVE-2015-5477 and similar BIND assertion-failure bugs cause named to abort on a malformed TKEY query; repeated restarts of the named process in a short window are the on-host symptom of remote denial-of-service exploitation.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where ActionType == "ProcessCreated"
| where FileName in~ ("named","named.exe","bind9")
| summarize RestartCount = count(), FirstStart = min(Timestamp), LastStart = max(Timestamp), CommandLines = make_set(ProcessCommandLine, 5), Parents = make_set(InitiatingProcessFileName, 5) by DeviceId, DeviceName, TimeBucket = bin(Timestamp, 1h)
| where RestartCount >= 5
| project TimeBucket, DeviceId, DeviceName, RestartCount, FirstStart, LastStart, Parents, CommandLines
```

**Tuning notes:** Planned config reloads, package upgrades and container orchestration can restart named repeatedly; exclude maintenance windows and hosts where named runs in a short-lived container. Tune RestartCount to the baseline of each DNS server, and correlate with inbound UDP/53 bursts in DeviceNetworkEvents on the same host.
