## 1) Java/Tomcat Application Server Spawning OS Shell (Ahsay AhsayCBS Exploitation CVE-2026-105133/105134)

**Tactic:** InitialAccess  
**ATT&CK:** T1190  
**Severity:** High  
**Purpose:** AhsayCBS runs as a Java/Tomcat web application. The chained auth-bypass + command-injection flaw in /rps/api/json/UpdateReceivers.do results in OS commands executed by the Java process. Detect any shell or recon utility spawned by a Java/Tomcat server process.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFileName in~ ("java.exe","javaw.exe","tomcat.exe","tomcat9.exe","tomcat10.exe","java","catalina.sh")
| where FileName in~ ("cmd.exe","powershell.exe","pwsh.exe","wscript.exe","cscript.exe","mshta.exe","certutil.exe","bitsadmin.exe","curl.exe","whoami.exe","net.exe","net1.exe","sh","bash","curl","wget","python3")
| project Timestamp, DeviceId, DeviceName, AccountName, FileName, ProcessCommandLine, FolderPath, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessFolderPath, InitiatingProcessAccountName, ReportId
```

**Tuning notes:** Scope to servers hosting AhsayCBS/Tomcat if possible (DeviceName prefix or device group). Some Java apps legitimately shell out (backup pre/post scripts, monitoring agents) — build an allowlist of known parent command lines and child command lines. Investigate any child process whose command line contains base64, downloaders, or user/group enumeration.

## 2) Exchange PowerShell Cmdlet History Logs Deleted (Sigma a55349d8)

**Tactic:** DefenseEvasion  
**ATT&CK:** T1070  
**Severity:** High  
**Purpose:** Translation of the Sigma rule: deletion of Exchange LocalPowerShell cmdlet infrastructure logs, a common anti-forensics step after hands-on-keyboard activity on an Exchange server.

```kusto
DeviceFileEvents
| where Timestamp > ago(1d)
| where ActionType in ("FileDeleted", "FileRenamed")
| where FolderPath has @"\Logging\CmdletInfra\LocalPowerShell\Cmdlet\" and FolderPath contains "_Cmdlet_"
| project Timestamp, DeviceName, DeviceId, ActionType, FileName, FolderPath, InitiatingProcessFileName, InitiatingProcessFolderPath, InitiatingProcessCommandLine, InitiatingProcessAccountName, InitiatingProcessParentFileName, ReportId
```

**Tuning notes:** Exchange log housekeeping/retention trimming is performed by Microsoft.Exchange.* service processes and some backup suites — allowlist those specific initiating process paths, but alert on deletions by cmd.exe, powershell.exe, explorer.exe, or any process running under an interactive/admin session.

## 3) EVTX File Created Outside Standard Event Log Locations (Sigma 65236ec7)

**Tactic:** DefenseEvasion  
**ATT&CK:** T1070.001  
**Severity:** Medium  
**Purpose:** Translation of the Sigma rule: creation of .evtx files outside C:\Windows\System32\winevt\Logs, indicating event log export for exfiltration/review or relocation of logging to evade controls.

```kusto
DeviceFileEvents
| where Timestamp > ago(1d)
| where ActionType in ("FileCreated", "FileRenamed", "FileModified")
| where FileName endswith ".evtx"
| where not(FolderPath startswith @"C:\Windows\System32\winevt\Logs\")
| where not(FolderPath startswith @"C:\ProgramData\Microsoft\Windows\Containers\BaseImages\" and FolderPath contains @"\Windows\System32\winevt\Logs\")
| project Timestamp, DeviceName, DeviceId, ActionType, FileName, FolderPath, FileSize, InitiatingProcessFileName, InitiatingProcessFolderPath, InitiatingProcessCommandLine, InitiatingProcessAccountName, ReportId
```

**Tuning notes:** Backup/imaging software, SCCM/Intune diagnostics (MDMDiagnostics), wevtutil epl during troubleshooting, and support bundle collectors will fire — allowlist those initiating process paths and known collection directories. Prioritize creations by wevtutil.exe/powershell.exe into user profile, temp, or network share paths.

## 4) Nslookup TXT-Record Download Cradle Launched by PowerShell (Sigma 1b3b01c7)

**Tactic:** CommandAndControl  
**ATT&CK:** T1071.004  
**Severity:** High  
**Purpose:** Translation of the Sigma rule: PowerShell spawning nslookup with a TXT query type, a known download cradle that stages payloads or C2 instructions inside DNS TXT records.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where FileName =~ "nslookup.exe" or ProcessVersionInfoOriginalFileName =~ "nslookup.exe"
| where InitiatingProcessFileName in~ ("powershell.exe", "pwsh.exe")
| where ProcessCommandLine has_any (" -q=txt", " -querytype=txt", " -type=txt")
| project Timestamp, DeviceName, DeviceId, AccountName, FileName, ProcessCommandLine, FolderPath, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessFolderPath, InitiatingProcessParentFileName, ReportId
```

**Tuning notes:** Very low false-positive rate; occasional hits from admin DNS/SPF/DKIM validation scripts — allowlist specific script paths via InitiatingProcessCommandLine. Enrich by extracting the queried domain from ProcessCommandLine and checking domain age/reputation.

## 5) ClickFix: Script Interpreter Spawned by Explorer with Download/Encoded Payload

**Tactic:** Execution  
**ATT&CK:** T1204.004  
**Severity:** High  
**Purpose:** The 'Unknown Loader' cluster uses ClickFix social engineering, where the victim pastes an attacker-supplied command into the Run dialog, causing explorer.exe to launch powershell/mshta/curl with a remote payload. Detects this parent-child and command-line pattern.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where InitiatingProcessFileName =~ "explorer.exe"
| where FileName in~ ("powershell.exe","pwsh.exe","cmd.exe","mshta.exe","wscript.exe","cscript.exe","curl.exe","msiexec.exe","conhost.exe","rundll32.exe")
| where ProcessCommandLine has_any ("iwr ","Invoke-WebRequest","Invoke-Expression","IEX","DownloadString","DownloadFile","FromBase64String","-enc ","-EncodedCommand","-w hidden","-windowstyle hidden","http://","https://","curl ","certutil","bitsadmin","start-process","msiexec /i http")
| project Timestamp, DeviceName, DeviceId, AccountName, FileName, ProcessCommandLine, FolderPath, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessAccountName, ReportId
```

**Tuning notes:** Admins and developers occasionally launch PowerShell one-liners from the Run box — scope to non-IT user populations or correlate with a following outbound connection to a rare domain within 5 minutes. Allowlist internal management URLs/UNC paths.

## 6) ClickFix RunMRU Registry Artifact Containing Script/Download Command

**Tactic:** Execution  
**ATT&CK:** T1059.001  
**Severity:** High  
**Purpose:** When a victim pastes a ClickFix command into Win+R, Explorer records it under RunMRU. Detects RunMRU values containing interpreter or download keywords — a durable artifact of the social-engineering lure.

```kusto
DeviceRegistryEvents
| where Timestamp > ago(1d)
| where ActionType in ("RegistryValueSet", "RegistryKeyCreated")
| where RegistryKey has @"\Explorer\RunMRU"
| where RegistryValueData has_any ("powershell","pwsh","mshta","cmd.exe /c","curl ","certutil","bitsadmin","FromBase64String","-enc","iwr ","Invoke-WebRequest","http://","https://","\\\\")
| project Timestamp, DeviceName, DeviceId, InitiatingProcessAccountName, RegistryKey, RegistryValueName, RegistryValueData, InitiatingProcessFileName, InitiatingProcessCommandLine, ReportId
```

**Tuning notes:** IT staff frequently type UNC paths and mmc/powershell into Run — consider removing the '\\\\' and bare 'powershell' terms for admin groups, or alert only when the value also contains a URL, base64 blob, or hidden-window switch. Correlate with the matching process creation event.

## 7) Linux IoT Dropper Pattern: Remote Shell Script Piped to Interpreter / Chmod of Temp Binary (Mirai-style)

**Tactic:** Execution  
**ATT&CK:** T1059.004  
**Severity:** High  
**Purpose:** Mirai/Gafgyt loaders fetch a stage-1 shell script with wget/curl, pipe it to sh, then download architecture-specific binaries (ARM/MIPS) into /tmp, /var/run or /dev/shm, chmod them and execute. Detects this behavioral chain on Linux endpoints.

```kusto
DeviceProcessEvents
| where Timestamp > ago(1d)
| where FileName in~ ("sh","bash","dash","busybox","wget","curl","tftp","chmod")
| where (ProcessCommandLine has_any ("wget","curl","tftp") and ProcessCommandLine has_any ("| sh","|sh","| bash","|bash","-O-","-qO-"))
    or (ProcessCommandLine has_any ("chmod 777","chmod +x","chmod 755") and ProcessCommandLine has_any ("/tmp/","/var/run/","/dev/shm/","/var/tmp/","/mnt/"))
    or (ProcessCommandLine has "busybox" and ProcessCommandLine has_any ("wget","tftp","chmod"))
| project Timestamp, DeviceName, DeviceId, AccountName, FileName, ProcessCommandLine, FolderPath, InitiatingProcessFileName, InitiatingProcessCommandLine, InitiatingProcessFolderPath, ReportId
```

**Tuning notes:** Container build jobs, CI runners, and config-management tooling (Ansible, cloud-init) legitimately pipe scripts to sh — allowlist those initiating processes/accounts or exclude build hosts. Prioritize events where the parent is a web/service daemon or the download URL is a bare IP address.
